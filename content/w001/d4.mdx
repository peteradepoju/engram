solution={String.raw`
def intervals(spike_times):
    return [b - a for a, b in zip(spike_times, spike_times[1:])]

def cv(xs):
    m = sum(xs) / len(xs)
    sd = (sum((x - m) ** 2 for x in xs) / len(xs)) ** 0.5
    return sd / m

print(intervals([10, 15, 30, 31]))

def normalise(values):
    lo, hi = min(values), max(values)
    for i in range(len(values)):
        values[i] = (values[i] - lo) / hi
    return values

hint="Bug 1: the denominator should be the range, hi - lo. Bug 2: the loop overwrites the caller's list; build a new list instead."
solution={String.raw`
def normalise(values):
    lo, hi = min(values), max(values)
    return [(v - lo) / (hi - lo) for v in values]

print(normalise([2.0, 4.0, 6.0]))

A layout like this one, used by many labs, keeps every project tidy:

```text
my-project/
  README.md          what this is, how to run it
  data/raw/          never edited
  data/processed/    made by code
  src/               reusable functions
  notebooks/         exploration
  results/           figures and tables, made by code
  environment.yml    the exact packages used
```
