<Step n={1} title="Neurons as logic" minutes={20} />

A McCulloch-Pitts neuron has binary inputs $x_i \in \{0, 1\}$, weights $w_i$ and a threshold $\theta$. It outputs 1 if the weighted sum reaches the threshold:

$$
y = \begin{cases} 1 & \text{if } \sum_i w_i x_i \ge \theta \\ 0 & \text{otherwise} \end{cases}
$$

With the right weights and threshold, one neuron computes a logic gate. With two inputs and both weights equal to 1, a threshold of 2 gives AND (both must be on) and a threshold of 1 gives OR.

McCulloch and Pitts showed that networks of such units can compute any logical function. But someone has to choose the weights. Rosenblatt's step was to let the network **learn** them from examples.

<Step n={2} title="The perceptron as geometry" minutes={25} />

Move the threshold to the left side and call $b = -\theta$ the **bias**. The perceptron outputs $+1$ or $-1$:

$$
\hat{y} = \operatorname{sign}(\mathbf{w}\cdot\mathbf{x} + b) = \operatorname{sign}(w_1 x_1 + w_2 x_2 + b)
$$

The set of points where $w_1 x_1 + w_2 x_2 + b = 0$ is a straight line. Points on one side get $+1$, points on the other side get $-1$. So a perceptron with two inputs is just a line drawn through the plane, and learning means moving the line. With more inputs the line becomes a flat plane (a **hyperplane**).

<Step n={3} title="The learning rule" minutes={30} />

Rosenblatt's rule is simple. Show the perceptron one example $(\mathbf{x}, y)$ with $y = \pm 1$.

- If it is classified correctly, do nothing.
- If it is wrong, nudge the weights towards the right answer:

$$
\mathbf{w} \leftarrow \mathbf{w} + \eta\, y\, \mathbf{x}, \qquad b \leftarrow b + \eta\, y
$$

Here $\eta$ is the **learning rate**, a small positive number.

<Derivation title="Why the rule helps on the example it got wrong">
  <div>The perceptron's raw output on $\mathbf{x}$ is $a = \mathbf{w}\cdot\mathbf{x} + b$. It is wrong when $a$ has the opposite sign to $y$, that is when $y\,a \le 0$.</div>
  <div>After the update the new output is $a' = (\mathbf{w} + \eta y \mathbf{x})\cdot\mathbf{x} + (b + \eta y)$.</div>
  <div>Expand: $a' = \mathbf{w}\cdot\mathbf{x} + b + \eta y(\mathbf{x}\cdot\mathbf{x} + 1) = a + \eta y(\lVert\mathbf{x}\rVert^2 + 1)$.</div>
  <div>Multiply by $y$ and use $y^2 = 1$: $y a' = y a + \eta(\lVert\mathbf{x}\rVert^2 + 1)$.</div>
  <div>The added term is always positive, so $y\,a$ goes up: the output moves towards the correct sign. One update may not be enough, but each one helps on that example.</div>
</Derivation>

A stronger result, the **perceptron convergence theorem** (Novikoff, 1962), says that if some line separates the two classes perfectly, the rule finds such a line after a finite number of mistakes. You will prove it in Week 56.

import numpy as np

def train(X, y, eta=0.1, epochs=20):
    w = np.zeros(X.shape[1])
    b = 0.0
    for epoch in range(epochs):
        for x_i, y_i in zip(X, y):
            if y_i * (w @ x_i + b) <= 0:
                w = w + eta * y_i * x_i
                b = b + eta * y_i
    return w, b

rng = np.random.default_rng(0)
X = rng.normal(size=(60, 2))
y = np.where(X[:, 0] - X[:, 1] > 0, 1, -1)
w, b = train(X, y)
print("weights:", w, "bias:", b)
print("accuracy:", (np.where(X @ w + b >= 0, 1, -1) == y).mean())

Where could such a teaching signal come from in the brain? The cerebellum is one candidate: climbing fibres carry error-like signals to Purkinje cells, and the Marr-Albus theory (1969, 1971) proposed that the cerebellum learns like a perceptron. You will meet it in Week 122.

<Step n={4} title="XOR and the first AI winter" minutes={25} />

XOR (exclusive or) outputs 1 when exactly one input is on. Plot the four input points: $(0,0)$ and $(1,1)$ are class 0, $(0,1)$ and $(1,0)$ are class 1. They sit on opposite corners of a square. No single straight line puts both 1s on one side and both 0s on the other.

However long you train, the accuracy stays at or below 75%. In their 1969 book *Perceptrons*, Marvin Minsky and Seymour Papert proved limits like this for single-layer perceptrons. Their analysis contributed to a sharp fall in funding and interest in neural networks during the 1970s, often called the first **AI winter**.

The fix is a second layer. XOR is "OR but not AND". Two hidden neurons compute OR and AND, and an output neuron combines them.

You just built a two-layer network by hand. The catch is that the perceptron rule cannot train the hidden layer: when the output is wrong, which hidden neuron is to blame? That is the **credit assignment problem** from Day 2. Backpropagation solved it for artificial networks in the 1980s. You will derive it in Week 80. Whether the brain has its own solution is still open.

<Prove title="XOR is not linearly separable" task="Prove that no $w_1, w_2, b$ satisfy all four conditions: $b \lt 0$ for $(0,0)$, $w_2 + b \ge 0$ for $(0,1)$, $w_1 + b \ge 0$ for $(1,0)$ and $w_1 + w_2 + b \lt 0$ for $(1,1)$.">

Add the two middle inequalities: $w_1 + w_2 + 2b \ge 0$.

The last condition says $w_1 + w_2 + b \lt 0$. Subtract it from the sum: $(w_1 + w_2 + 2b) - (w_1 + w_2 + b) = b$, and a non-negative number minus a negative number is positive, so $b \gt 0$.

But the first condition says $b \lt 0$. Contradiction. So no line separates XOR.

</Prove>

<Key title="Before you go">
<ul>
<li>Threshold neurons compute logic; networks of them compute anything logical.</li>
<li>A perceptron is a line (hyperplane) that separates classes; learning moves the line.</li>
<li>The rule $\mathbf{w} \leftarrow \mathbf{w} + \eta y \mathbf{x}$ fixes mistakes one at a time and converges when the classes are separable.</li>
<li>XOR needs a hidden layer, and training hidden layers needs a solution to credit assignment.</li>
