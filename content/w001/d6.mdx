<Step n={2} title="Weekly challenge: can a perceptron read a neuron?" minutes={50} />

This challenge joins the week together. A LIF neuron receives two inputs. You record whether it fires, then train a perceptron to predict, from the two inputs alone, whether the neuron will fire. Is the neuron's behaviour linearly separable?

**Part A (setup).** Run this cell. It defines `fires(I1, I2)`, which returns 1 if the neuron spikes at least once when it receives currents `I1` and `I2` (each through a synapse, with the total current `0.8*I1 + 1.2*I2`).

<PyCell code={String.raw`
  import numpy as np

  def fires(I1, I2, T=200.0, dt=0.1):
      tau, R, v_rest, v_th, v_reset = 20.0, 10.0, -70.0, -54.0, -75.0
      I = 0.8 * I1 + 1.2 * I2
      v = v_rest
      for _ in range(int(T / dt)):
          v += dt / tau * (-(v - v_rest) + R * I)
          if v >= v_th:
              return 1
      return 0

  rng = np.random.default_rng(3)
  inputs = rng.uniform(0, 2.5, size=(200, 2))
  labels = np.array([fires(a, b) for a, b in inputs])
  print("fraction of trials with a spike:", labels.mean())
`} />

solution={String.raw`
  import numpy as np

  y = np.where(labels == 1, 1, -1)
  def train(X, y, eta=0.05, epochs=200):
      w, b = np.zeros(X.shape[1]), 0.0
      for _ in range(epochs):
          for x_i, y_i in zip(X, y):
              if y_i * (w @ x_i + b) <= 0:
                  w = w + eta * y_i * x_i
                  b = b + eta * y_i
      return w, b

  w, b = train(inputs, y)
  accuracy = (np.where(inputs @ w + b >= 0, 1, -1) == y).mean()
  print("w =", w, "b =", b, "accuracy =", accuracy)

<Step n={3} title="Derivation set" minutes={20} />

<Prove title="1. The LIF firing rate" task="With constant current above threshold, a LIF neuron starts each interval at $V_\text{reset}$, rises towards $V_\infty = V_\text{rest} + RI$, and spikes at $V_\text{th}$. Using the solution $V(t) = V_\infty + (V_\text{reset} - V_\infty)e^{-t/\tau}$, find the interspike interval $T$ and hence the firing rate $1/T$ (ignore any refractory period).">

Set $V(T) = V_\text{th}$: $V_\text{th} - V_\infty = (V_\text{reset} - V_\infty)e^{-T/\tau}$.

So $e^{-T/\tau} = \dfrac{V_\infty - V_\text{th}}{V_\infty - V_\text{reset}}$ and $T = \tau \ln\dfrac{V_\infty - V_\text{reset}}{V_\infty - V_\text{th}}$.

The rate is $f = 1/T$. As $I$ grows, $V_\infty$ grows, the log ratio tends to 0, and the rate grows without limit (a real neuron has a refractory period that caps it). Just above threshold, $V_\infty - V_\text{th}$ is tiny, the log is large and the rate is near zero: the f-I curve starts at zero and rises, like a smoothed ReLU.

</Prove>

<Prove title="2. The perceptron update in one line" task="Show that on a mistake the perceptron update increases $y(\mathbf{w}\cdot\mathbf{x} + b)$ by exactly $\eta(\lVert\mathbf{x}\rVert^2 + 1)$. How large must $\eta$ be to fix the mistake in one step?">

From Day 5: $y a' = y a + \eta(\lVert\mathbf{x}\rVert^2 + 1)$.

To be correct after one step we need $y a' \gt 0$, that is $\eta \gt \dfrac{-y a}{\lVert\mathbf{x}\rVert^2 + 1}$. Since the example was wrong, $-ya \ge 0$, so a large enough learning rate always fixes the current example, but it may break others. That trade-off is why learning rates matter.

</Prove>

<Step n={5} title="Deep read and critique" minutes={25} />

Give Hassabis et al. (2017) its third pass: re-read it, re-create its argument in your own words, and challenge it. Then write a critique in the paper's page (**Papers**, then the paper, then **My critique**) using the five headings:

1. **Claim.** What is the paper's main claim, in one sentence?
2. **Evidence.** What supports it? (For a review: which examples carry the argument?)
3. **Method.** How is the argument built? What is left out?
4. **Weakness.** Where is it weakest or most one-sided?
5. **Next.** What would you do next, if you were writing the follow-up?

<Callout kind="research">
A critique is not an attack. The best critiques say clearly what a paper does well, then name its limits precisely. Practising this weekly is what makes peer review, and your own papers, much easier later.
