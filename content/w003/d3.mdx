<Step n={1} title="Why tables" minutes={15} />

Last week your data were arrays: every number the same kind of thing (a spike count), arranged by neuron, trial and time. Behaviour is different. Each trial has several variables of different types: the contrast on each side (numbers), the mouse's choice (a category), the reaction time (a number, sometimes missing), whether it was rewarded (true or false). A **DataFrame** holds such data: columns have names and their own types, rows have labels, and operations line up by label.

In this course arrays hold neural activity and DataFrames hold everything about the trials. Most analyses join the two.

<Step n={2} title="A session as a DataFrame" minutes={25} />

The cell below simulates one session of a task like the International Brain Laboratory's (this week's deep read): a grating appears on the left or right at one of several contrasts, and the mouse turns a wheel to choose a side. Run it, then look at the table.

<PyCell code={String.raw`
  import numpy as np
  import pandas as pd

  def make_session(seed=0, n=600, bias=0.05, sigma=0.15, lapse=0.06):
      rng = np.random.default_rng(seed)
      contrasts = np.array([0, 0.0625, 0.125, 0.25, 1.0])
      side = rng.choice([-1, 1], n)                          # -1 left, 1 right
      c = rng.choice(contrasts, n)
      signed = side * c
      p_right = lapse + (1 - 2 * lapse) / (1 + np.exp(-(signed - bias) / sigma))
      choice = np.where(rng.random(n) < p_right, 1, -1)
      timeout = rng.random(n) < 0.04                         # no response on some trials
      rt = 0.25 + 0.6 * np.exp(-3 * c) * rng.lognormal(0, 0.35, n)
      return pd.DataFrame({
          "trial": np.arange(1, n + 1),
          "contrast_left": np.where(side == -1, c, 0.0),
          "contrast_right": np.where(side == 1, c, 0.0),
          "choice": np.where(timeout, 0, choice),            # 0 means no response
          "rt": np.where(timeout, np.nan, rt.round(3)),      # seconds
          "feedback": np.where(timeout, -1, np.where(choice == side, 1, -1)),
      })

  df = make_session()
  df.head(8)
`} />

<Step n={3} title="Selecting rows and columns" minutes={30} />

| You want | Code |
| --- | --- |
| One column (a Series) | `df["rt"]` |
| Several columns | `df[["choice", "rt"]]` |
| Rows by condition | `df[df["rt"] < 0.5]` |
| Rows and columns by label | `df.loc[df["feedback"] == 1, ["trial", "rt"]]` |
| Rows and columns by position | `df.iloc[:10, :3]` |
| Rows by a readable condition | `df.query("choice == 1 and rt < 0.5")` |

Conditions combine with `&`, `|` and `~` and need brackets, exactly as with NumPy masks (Week 2, Day 2).

At zero contrast there is no correct answer to see; the task assigns the rewarded side at random, so a guessing mouse is right about half the time. Easy trials are not 100 per cent correct either. Those errors are **lapses**, and you will measure them tomorrow.

<Step n={4} title="New columns and missing data" minutes={20} />

Derived columns make analysis readable. The single most useful one here is **signed contrast**: right contrast minus left contrast, so negative means the stimulus was on the left.

<PyCell id="derived" title="Signed contrast and clean trials" tests={String.raw`

  def test_signed():

code={String.raw`
  df["signed_contrast"] = ...
  df["chose_right"] = ...
  clean = ...

`}

Missing values appear as `NaN`. Most pandas summaries **skip them by default**: `df["rt"].mean()` averages only the trials that have a reaction time. That answers today's prediction, and it is usually what you want, but it is a decision. Always count how many values were missing (`df["rt"].isna().sum()`) and report it.

<Step n={5} title="A first look at groupby" minutes={15} />

Almost every behavioural analysis is "compute something for each condition". pandas does this with `groupby`, in three steps: **split** the rows into groups, **apply** a summary to each, **combine** the results into a new table. Try it on a tiny table:

<PyCell code={String.raw`
  summary = clean.groupby("signed_contrast").agg(
      n=("trial", "size"),
      p_right=("chose_right", "mean"),
      median_rt=("rt", "median"),

That table is a psychometric curve and a chronometric curve (reaction time against difficulty) in seven rows. Tomorrow you will plot and fit it.

<Key title="Before you go">
<ul>
<li>Arrays for neural activity, DataFrames for trials and metadata.</li>
<li>Select with conditions, `.loc` (labels) and `.iloc` (positions); assign with `.loc` in one step.</li>
<li>Missing values are skipped by most summaries: count them and say so.</li>
<li>groupby splits by condition, applies a summary and combines the results.</li>
</ul>
