<Step n={1} title="The psychometric curve" minutes={25} />

A **psychometric curve** plots the probability of one choice (here, "right") against the signed strength of the evidence. It is the standard summary of perceptual decisions, used for humans in the 1800s and for every mouse in the IBL study.

$$
P(\text{right} \mid c) = \lambda_L + (1 - \lambda_L - \lambda_R)\,\frac{1}{1 + e^{-(c - \mu)/\sigma}}
$$

Four parameters, each with a meaning:

- **Bias** $\mu$: the contrast at which the animal is indifferent. Non-zero means it prefers a side.
- **Threshold** $\sigma$: how much contrast it needs; smaller means more sensitive and a steeper curve.
- **Lapse rates** $\lambda_L$, $\lambda_R$: errors even on the easiest trials, often blamed on inattention or exploration.

The figure uses a single lapse rate for both sides. Move the sliders and resample to see how noisy 40 trials per contrast are.

<PyCell code={String.raw`
  import numpy as np
  import pandas as pd
  import matplotlib.pyplot as plt

  def make_session(seed=0, n=600, bias=0.05, sigma=0.15, lapse=0.06):
      rng = np.random.default_rng(seed)
      contrasts = np.array([0, 0.0625, 0.125, 0.25, 1.0])
      side = rng.choice([-1, 1], n)
      c = rng.choice(contrasts, n)
      signed = side * c
      p_right = lapse + (1 - 2 * lapse) / (1 + np.exp(-(signed - bias) / sigma))
      choice = np.where(rng.random(n) < p_right, 1, -1)
      timeout = rng.random(n) < 0.04
      rt = 0.25 + 0.6 * np.exp(-3 * c) * rng.lognormal(0, 0.35, n)
      df = pd.DataFrame({
          "trial": np.arange(1, n + 1),
          "contrast_left": np.where(side == -1, c, 0.0),
          "contrast_right": np.where(side == 1, c, 0.0),
          "choice": np.where(timeout, 0, choice),
          "rt": np.where(timeout, np.nan, rt.round(3)),
          "feedback": np.where(timeout, -1, np.where(choice == side, 1, -1)),
      })
      df["signed_contrast"] = df["contrast_right"] - df["contrast_left"]
      df["chose_right"] = df["choice"] == 1
      return df

  df = make_session()
  valid = df[df["choice"] != 0]            # drop no-response trials
  print(len(valid), "valid trials")

<Derivation title="The standard error of a proportion">
  <div>

Each trial is a Bernoulli variable: $X = 1$ (chose right) with probability $p$, else 0. Its mean is $p$ and its variance is $p(1-p)$.

  </div>
  <div>

The proportion $\hat{p}$ is the mean of $n$ independent trials, so by Week 1's argument its variance is $p(1-p)/n$.

  </div>
  <div>

$$
\text{SE}(\hat{p}) = \sqrt{\frac{p(1-p)}{n}}
$$

It is largest at $p = 0.5$ (the hard, uncertain contrasts) and shrinks towards 0 and 1. That is why the error bars in the middle of a psychometric curve are always the widest.

  </div>
</Derivation>

Two more grouping tools:

- **Several keys**: `df.groupby(["session", "signed_contrast"])` makes one group per combination.
- **transform** returns a result the same length as the original, so you can add it as a column. For example `df["rt_z"] = df.groupby("signed_contrast")["rt"].transform(lambda x: (x - x.mean()) / x.std())` z-scores reaction times within each contrast.

<Prove title="Where the curve is steepest" task="Ignoring lapses, show that $P(c) = 1/(1 + e^{-(c - \mu)/\sigma})$ has its steepest point at $c = \mu$, with slope $1/(4\sigma)$. Why does this justify calling $\sigma$ a threshold?">

Let $u = (c - \mu)/\sigma$ and $s(u) = 1/(1 + e^{-u})$. The logistic function satisfies $s'(u) = s(u)(1 - s(u))$.

By the chain rule $dP/dc = s(u)(1 - s(u))/\sigma$. The product $s(1-s)$ is largest when $s = 1/2$, that is $u = 0$, or $c = \mu$, where it equals $1/4$. So the maximum slope is $1/(4\sigma)$.

A small $\sigma$ gives a steep curve: a small change in contrast moves the choice from left to right. So $\sigma$ measures how much evidence the animal needs, which is what a threshold is.

</Prove>
