<Step n={2} title="Weekly challenge: are mice the same in every lab?" minutes={60} />

**The data.** Three labs each ran four mice for one session. All mice learned the same task, but each has its own bias, threshold and lapse rate, and the labs might differ. Run the cell to build the trial table `trials`.

<PyCell code={String.raw`
  import matplotlib.pyplot as plt
  from scipy.optimize import curve_fit

  def psychometric(c, bias, sigma, lapse):
      return lapse + (1 - 2 * lapse) / (1 + np.exp(-(c - bias) / sigma))

  rng = np.random.default_rng(2026)
  contrasts = np.array([0, 0.0625, 0.125, 0.25, 1.0])
  rows = []
  for lab, lab_sigma in [("cshl", 0.14), ("ucl", 0.16), ("champalimaud", 0.15)]:
      for m in range(4):
          mouse = f"{lab}_{m + 1:02d}"
          bias = rng.normal(0, 0.08)
          sigma = abs(rng.normal(lab_sigma, 0.03)) + 0.05
          lapse = rng.uniform(0.02, 0.12)
          n = 500
          side = rng.choice([-1, 1], n); c = rng.choice(contrasts, n); signed = side * c
          chose_right = rng.random(n) < psychometric(signed, bias, sigma, lapse)
          rt = 0.25 + 0.6 * np.exp(-3 * c) * rng.lognormal(0, 0.35, n)
          rows.append(pd.DataFrame({"lab": lab, "mouse": mouse, "signed_contrast": signed, "chose_right": chose_right, "rt": rt}))
  trials = pd.concat(rows, ignore_index=True)
  print(trials.shape); trials.head()

<Step n={3} title="Derivation set" minutes={10} />

<Prove title="1. Comparing two proportions" task="Lab A's mice choose right on 60 per cent of 400 zero-contrast trials; lab B's on 50 per cent of 400. Estimate the standard error of the difference between the two proportions, assuming independent trials. Is a 10-point difference large compared with it?">

Each proportion has standard error $\sqrt{p(1-p)/n}$: $\sqrt{0.6 \times 0.4/400} \approx 0.0245$ and $\sqrt{0.5 \times 0.5/400} = 0.025$.

For independent estimates variances add: $\text{SE}_{\text{diff}} = \sqrt{0.0245^2 + 0.025^2} \approx 0.035$.

The difference, 0.10, is about 2.9 standard errors, so it is unlikely to be chance alone. But trials from one mouse are not truly independent (each mouse has its own bias), so the honest unit of analysis is the mouse, not the trial: a point you will meet again in Week 59.

</Prove>
