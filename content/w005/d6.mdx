<Step n={2} title="Weekly challenge: an encoding model of visual cortex" minutes={60} />

**The experiment.** A participant views 160 natural images in an fMRI scanner: 120 for training and 40 held out for testing. Each image is described by 150 features (think of the outputs of a bank of oriented filters, Week 4), and these features are correlated with each other, as real image features are. We record 30 voxels in visual cortex. Each voxel responds to a weighted sum of a few features plus a lot of noise. There are more features than training images, so ordinary least squares cannot even be solved uniquely. Run the cell to build the data.

<PyCell code={String.raw`
  import matplotlib.pyplot as plt
  rng = np.random.default_rng(2011)
  n_train, n_test, p, V = 120, 40, 150, 30
  mix = rng.normal(size=(p, p)) * 0.5 + np.eye(p)                  # makes the features correlated
  F_train = rng.normal(size=(n_train, p)) @ mix / np.sqrt(p) * 3     # (120, 150) image features
  F_test = rng.normal(size=(n_test, p)) @ mix / np.sqrt(p) * 3       # (40, 150)
  W_true = rng.normal(size=(p, V)) * (rng.random((p, V)) < 0.2)      # each voxel uses about 30 features
  scale = (F_train @ W_true).std(axis=0)
  Y_train = F_train @ W_true + rng.normal(0, 1, (n_train, V)) * scale  # (120, 30) voxel responses
  Y_test = F_test @ W_true + rng.normal(0, 1, (n_test, V)) * scale     # (40, 30)

  def voxel_r(Y, P):
      """Correlation between measured and predicted responses, one value per voxel (column)."""
      Yc, Pc = Y - Y.mean(axis=0), P - P.mean(axis=0)
      return (Yc * Pc).sum(axis=0) / np.sqrt((Yc ** 2).sum(axis=0) * (Pc ** 2).sum(axis=0))

  print(F_train.shape, Y_train.shape, "rank of F_train:", np.linalg.matrix_rank(F_train))

Solving for all 30 voxels at once is just matrix multiplication doing its job: each column of $B$ is a separate ridge regression, but they share the same $X^\top X + \lambda I$, so one solve handles them all. Real studies fit tens of thousands of voxels this way.

<Step n={3} title="Derivation set" minutes={10} />

<Prove title="1. The dual form of ridge" task="Show that $(X^\top X + \lambda I)^{-1}X^\top = X^\top(XX^\top + \lambda I)^{-1}$ for $\lambda \gt 0$. Why is the right-hand side cheaper to compute when there are far more features than images?">

Start from the identity $X^\top(XX^\top + \lambda I) = X^\top X X^\top + \lambda X^\top = (X^\top X + \lambda I)X^\top$. Both bracketed matrices are invertible for $\lambda \gt 0$. Multiply on the left by $(X^\top X + \lambda I)^{-1}$ and on the right by $(XX^\top + \lambda I)^{-1}$ to get the result.

With $n$ images and $p$ features, the left side inverts a $p \times p$ matrix and the right side an $n \times n$ matrix. When $p$ is much larger than $n$ (deep-network features often number in the hundreds of thousands), the dual form is far cheaper. It is also the doorway to kernel methods (Week 57).

</Prove>

<Prove title="2. Composition of linear layers" task="A two-layer network computes $\mathbf{y} = W_2(W_1\mathbf{x})$ with no nonlinearity. Show that it is equivalent to a single layer, and give the rank bound on the combined matrix when $W_1$ is 3 by 100 and $W_2$ is 100 by 3.">

By associativity, $W_2(W_1\mathbf{x}) = (W_2W_1)\mathbf{x}$, a single matrix. The rank of a product is at most the smallest rank of its factors, and $W_1$ has rank at most 3, so $W_2W_1$, a 100 by 100 matrix, has rank at most 3. Stacking linear layers adds no expressive power; it can only squeeze information through the narrowest layer. That is why deep networks need nonlinearities (Week 80).

</Prove>

<Step n={5} title="Deep read and critique" minutes={25} />

Give Naselaris, Kay, Nishimoto and Gallant (2011) its third pass and write your critique under the five headings. Focus on one question: **when an encoding model built on some feature space predicts a voxel well, what has been learned about the brain?** A model can predict well because its features capture what the region computes, or because they happen to correlate with what it computes. Think about how comparing several feature spaces on the same data, as the authors recommend, helps to separate the two.
