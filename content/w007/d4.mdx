<Step n={1} title="Arranging the data" minutes={25} />

A typical experiment gives an array of firing rates with shape **neurons × conditions × time** (after averaging over repeated trials of each condition). PCA needs a matrix with **observations as rows and variables as columns**. For population analysis the variables are the neurons, and each moment of each condition is one observation: a point in the 60-dimensional state space of Week 4. So the data matrix is $(C \cdot T) \times N$.

Run the next cell to simulate the experiment. Every neuron mixes three hidden signals with its own weights: a rotation whose phase depends on the reach direction, and a slow ramp. Spikes are Poisson, recorded on 40 trials of each condition in 20 ms bins, and some neurons fire far more than others.

<PyCell code={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt
  rng = np.random.default_rng(2012)
  N, C, T, K, dt = 60, 8, 50, 40, 0.02             # neurons, conditions, time bins, trials, bin width (s)
  t = np.linspace(0, 1, T)
  theta = np.arange(C) * 2 * np.pi / C
  env = np.sin(np.pi * t)
  z = np.zeros((3, C, T))
  for c in range(C):
      phase = 2 * np.pi * 0.8 * t + theta[c]
      z[0, c], z[1, c], z[2, c] = env * np.cos(phase), env * np.sin(phase), t
  mixing = rng.normal(size=(N, 3))
  gain = rng.uniform(0.3, 3, N)                     # some neurons fire much more than others
  rate = np.clip(gain[:, None, None] * (15 + 12 * np.einsum("nk,kct->nct", mixing, z)), 0, None)
  counts = rng.poisson(rate[..., None] * dt, size=(N, C, T, K))
  psth = counts.mean(axis=-1) / dt                  # trial-averaged rate in Hz, shape (60, 8, 50)
  print(psth.shape)
  fig, ax = plt.subplots(1, 3, figsize=(9, 2.5), sharex=True)
  for a, n in zip(ax, [0, 1, 2]):
      a.plot(t, psth[n].T); a.set_title(f"neuron {n}"); a.set_xlabel("time (s)")
  plt.tight_layout(); plt.show()

<Step n={2} title="Normalisation" minutes={20} />

PCA finds directions of greatest variance, and variance depends on units. A neuron firing at 100 Hz with a 40 Hz swing contributes far more variance than one at 5 Hz with a 2 Hz swing, so without normalisation the top components describe the few loudest neurons. Dividing every neuron by its standard deviation (z-scoring) goes too far the other way: a nearly silent neuron's noise is blown up to the same size as a strongly modulated neuron's signal.

The usual compromise in population studies is **soft normalisation**: divide each neuron's rate by its range plus a constant,

$$
\tilde{r}_n = \frac{r_n}{\max r_n - \min r_n + 5\ \text{Hz}}
$$

Strongly modulated neurons end up with a range near 1, while weakly modulated ones are shrunk rather than inflated. The constant (5 Hz is the common choice) sets the boundary between "weak" and "strong".

Sixty messy firing-rate curves collapse onto eight clean loops that rotate in the PC1 to PC2 plane, each reach starting at a different phase. Three components capture about 80% of the variance. That answers the prediction, and the remaining components hold little more than Poisson noise. Churchland and colleagues (2012) found rotations like these in real motor cortex and argued that they reflect the dynamics that generate movement (Week 41), the representation-versus-dynamics debate you met in Week 4.

<Video id="Lsue2gEM9D0" title="PCA in Python" by="StatQuest with Josh Starmer" note="Doing PCA in Python with scikit-learn, including scaling the data first and drawing the scree plot." />

The components are not neurons. Each is a weighted combination of all 60, and PC1 has no special meaning beyond carrying the most variance. Rotating the top three axes within their subspace would describe the data equally well, which is why later methods (Week 61, Week 116) look for axes that are easier to interpret.

<Step n={4} title="How many dimensions?" minutes={25} />

"Three components explain 80%" depends on picking 80%. A threshold-free summary of how spread out the variance is is the **participation ratio**:

$$
\text{PR} = \frac{\left(\sum_i\lambda_i\right)^2}{\sum_i\lambda_i^2}
$$

If all the variance is in one component, PR is 1; if it is spread equally over $d$ components, PR is $d$. It is widely used to compare the dimensionality of neural activity across areas, tasks and models (Gao and Ganguli, 2015).

The participation ratio comes out a little above 4: the three signal components, which have unequal variances, count as fewer than 3, while the long tail of small noise components adds a bit more than 1. Both numbers depend on the noise, which inflates every estimate of dimensionality. Separating signal dimensions from noise dimensions honestly is tomorrow's topic.

<Prove title="Bounds on the participation ratio" task="For non-negative eigenvalues $\lambda_1, \dots, \lambda_n$, not all zero, show that $1 \leq \text{PR} \leq n$, with PR $= n$ exactly when all eigenvalues are equal.">

**Upper bound.** Apply Cauchy-Schwarz (Week 4) to the vectors $(\lambda_1, \dots, \lambda_n)$ and $(1, \dots, 1)$: $\left(\sum_i\lambda_i\right)^2 \leq n\sum_i\lambda_i^2$. Dividing gives PR $\leq n$, with equality when the two vectors are parallel, that is when all eigenvalues are equal.

**Lower bound.** Because every $\lambda_i \geq 0$, expanding the square gives $\left(\sum_i\lambda_i\right)^2 = \sum_i\lambda_i^2 + \sum_{i \neq j}\lambda_i\lambda_j \geq \sum_i\lambda_i^2$, so PR $\geq 1$, with equality when only one eigenvalue is nonzero.

</Prove>
