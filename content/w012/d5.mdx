<Step n={1} title="The perceptron" minutes={25} />

Rosenblatt's perceptron (Week 1's classic paper) outputs $\hat{y} = \operatorname{sign}(\mathbf{w}\cdot\mathbf{x})$ for labels $y = \pm 1$ (absorb the bias as a weight on a constant input of 1). Its learning rule is: on a mistake, add $\eta\,y\,\mathbf{x}$ to the weights; otherwise do nothing.

This is SGD on the **perceptron loss** $\ell(\mathbf{w}) = \max(0, -y\,\mathbf{w}\cdot\mathbf{x})$, which is zero for correctly classified examples and grows with how far a misclassified example lies on the wrong side. Its gradient is $-y\mathbf{x}$ when the example is misclassified and zero otherwise, so an SGD step is exactly the perceptron update. The loss is convex (a maximum of two linear functions, Day 3), but it is zero on a whole region of correct solutions, so the perceptron stops at the first separating line it finds, not the best one.

<Step n={2} title="The convergence theorem" minutes={20} />

<Prove title="The perceptron converges on separable data (Novikoff, 1962)" task="Suppose every example satisfies $\lVert\mathbf{x}_t\rVert \leq R$ and some unit vector $\mathbf{u}$ separates the data with margin $\gamma \gt 0$: $y_t\,\mathbf{u}\cdot\mathbf{x}_t \geq \gamma$ for all t. Starting from $\mathbf{w} = \mathbf{0}$ with $\eta = 1$, show that the perceptron makes at most $(R/\gamma)^2$ mistakes.">

Let $\mathbf{w}_k$ be the weights after the $k$th mistake, made on example $(\mathbf{x}, y)$, so $\mathbf{w}_k = \mathbf{w}_{k-1} + y\mathbf{x}$.

**Progress towards u.** $\mathbf{u}\cdot\mathbf{w}_k = \mathbf{u}\cdot\mathbf{w}_{k-1} + y\,\mathbf{u}\cdot\mathbf{x} \geq \mathbf{u}\cdot\mathbf{w}_{k-1} + \gamma$, so after $k$ mistakes $\mathbf{u}\cdot\mathbf{w}_k \geq k\gamma$.

**Slow growth of length.** $\lVert\mathbf{w}_k\rVert^2 = \lVert\mathbf{w}_{k-1}\rVert^2 + 2y\,\mathbf{w}_{k-1}\cdot\mathbf{x} + \lVert\mathbf{x}\rVert^2 \leq \lVert\mathbf{w}_{k-1}\rVert^2 + R^2$, because the example was misclassified, so $y\,\mathbf{w}_{k-1}\cdot\mathbf{x} \leq 0$. Hence $\lVert\mathbf{w}_k\rVert^2 \leq kR^2$.

**Combine.** By Cauchy-Schwarz (Week 4), $k\gamma \leq \mathbf{u}\cdot\mathbf{w}_k \leq \lVert\mathbf{w}_k\rVert \leq \sqrt{k}R$, so $\sqrt{k} \leq R/\gamma$ and $k \leq (R/\gamma)^2$. The weights move steadily towards the separating direction while their length grows only like the square root of the number of mistakes, so mistakes must stop. If no separating direction exists, the bound fails and the perceptron cycles for ever, as the figure shows.

</Prove>

The perceptron separates the two stimuli after a hundred or so mistakes, far fewer than the bound. The bound printed here is very loose because it uses the margin of the perceptron's own final weights, which only just separate the data; the theorem's bound uses the best possible margin, which is larger. Either way it guarantees the perceptron stops.

<Step n={3} title="The delta rule" minutes={25} />

For a linear neuron $\hat{y} = \mathbf{w}\cdot\mathbf{x}$ with squared error $\ell = \frac{1}{2}(y - \hat{y})^2$, the SGD update is

$$
\Delta\mathbf{w} = \eta\,(y - \hat{y})\,\mathbf{x}
$$

the **delta rule** of Widrow and Hoff (1960), also called the LMS rule. Unlike the perceptron it learns from every example, in proportion to the size of the error, and it converges (with a small enough or decaying step) to the least-squares solution. It is the same "error times input" form you met as the outer-product gradient in Week 9, and the rule thought to describe some error-driven plasticity, such as learning in the cerebellum (Week 122).

<Step n={4} title="The tempotron" minutes={35} />

The perceptron and delta rule are about rates. Gütig and Sompolinsky (2006), today's paper, asked whether a neuron can learn from the **timing** of its inputs. The tempotron's membrane potential is a weighted sum of postsynaptic potentials, each a fixed kernel triggered by an input spike:

$$
V(t) = \sum_i w_i\sum_{t_i \lt t}K(t - t_i), \qquad K(s) = V_0\left(e^{-s/\tau} - e^{-s/\tau_s}\right)
$$

with membrane and synaptic time constants $\tau = 15$ ms and $\tau_s = 3.75$ ms (Week 10's leaky integration applied to synaptic currents). The neuron "fires" for a pattern if $V$ crosses threshold anywhere in the trial. The learning rule is error-driven and acts at the moment $t_{\max}$ when $V$ was largest: if it should have fired and did not, each synapse is strengthened by $\eta K(t_{\max} - t_i)$, its contribution to the voltage at that moment; if it fired and should not have, each is weakened by the same amount. This is gradient descent on a loss equal to how far the peak voltage fell short of (or exceeded) threshold.

The tempotron learns to fire for every positive pattern and stay silent for every negative one, within a dozen or so epochs. That answers the prediction. A rate-based neuron could not do this: every afferent fires exactly one spike in every pattern, so the total input is identical. The tempotron succeeds by weighting together afferents whose spikes happen to arrive close in time in the positive patterns, so that their PSPs add up to threshold, a coincidence detector tuned by learning.
