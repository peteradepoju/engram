<Step n={2} title="Weekly challenge" minutes={60} />

**The task.** Fifty orientation-tuned neurons respond to gratings at random orientations, and the decoder must report whether each grating is within 45° of the 45° diagonal. Spike counts are recorded in 200 ms windows on 2,000 trials; the first 1,500 are for training. The decoder is logistic regression, trained by gradient descent.

<PyCell code={String.raw`
  rng = np.random.default_rng(2018)
  N, T = 50, 2000
  prefs = np.linspace(0, np.pi, N, endpoint=False)
  theta = rng.uniform(0, np.pi, T)
  labels = (np.cos(2 * (theta - np.pi / 4)) > 0).astype(float)
  counts = rng.poisson((10 + 20 * np.exp(2 * (np.cos(2 * (theta[:, None] - prefs[None])) - 1))) * 0.2)
  train, test = np.arange(1500), np.arange(1500, T)
  def sigmoid(u): return 1 / (1 + np.exp(-u))
  def xent(w, Z, y):
      p = np.clip(sigmoid(Z @ w), 1e-12, 1 - 1e-12)
      return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
  def grad(w, Z, y): return Z.T @ (sigmoid(Z @ w) - y) / len(y)
  Z_raw = np.column_stack([counts, np.ones(T)])                    # raw spike counts plus a bias input
  print("mean count", counts.mean().round(2), "  largest count", counts.max())

Raw spike counts share a large common mean that dwarfs their differences, so one direction of the Hessian (all weights moving together against the bias) is enormously steeper than the rest: a condition number in the tens of thousands. That direction caps the learning rate, and everything else crawls. Z-scoring removes the shared offset and equalises the scales, and the same 200 steps get noticeably further. It is the cheapest optimisation trick there is.

**Part C: a non-convex problem.** Now a different decoding task: two neurons' responses, and a label that is positive when exactly one of them is above its mean (an XOR). No straight line separates the classes, so logistic regression, which is convex, cannot solve it. A network with three tanh hidden units can, but its loss is not convex.

<PyCell code={String.raw`
  X2 = rng.normal(size=(400, 2))
  y2 = ((X2[:, 0] > 0) ^ (X2[:, 1] > 0)).astype(float)

  def train_net(seed, H=3, steps=3000, lr=0.5):
      r = np.random.default_rng(seed)
      W1, b1, w2, b2 = r.normal(size=(2, H)), np.zeros(H), r.normal(size=H) * 0.5, 0.0
      for _ in range(steps):
          h = np.tanh(X2 @ W1 + b1); p = sigmoid(h @ w2 + b2); d = (p - y2) / len(y2)
          dh = np.outer(d, w2) * (1 - h ** 2)
          W1 -= lr * X2.T @ dh; b1 -= lr * dh.sum(axis=0); w2 -= lr * h.T @ d; b2 -= lr * d.sum()
      p = sigmoid(np.tanh(X2 @ W1 + b1) @ w2 + b2)
      return np.mean((p > 0.5) == y2)
  print("one network's accuracy:", train_net(0))
`} />

Logistic regression is stuck near chance: convexity guarantees it finds the best line, but no line is good. The networks solve the task, but not equally: some starts end at about 92% and others in poorer solutions near 75%, having settled into different local minima or plateaus. That is the price of non-convexity, and why deep learning practice runs several seeds and reports the spread.

<Prove title="1. The descent lemma" task="Suppose the gradient of L is Lipschitz with constant $\Lambda$: $\lVert\nabla L(\mathbf{a}) - \nabla L(\mathbf{b})\rVert \leq \Lambda\lVert\mathbf{a} - \mathbf{b}\rVert$, which implies $L(\mathbf{b}) \leq L(\mathbf{a}) + \nabla L(\mathbf{a})\cdot(\mathbf{b} - \mathbf{a}) + \frac{\Lambda}{2}\lVert\mathbf{b} - \mathbf{a}\rVert^2$. Show that one gradient step with $\eta = 1/\Lambda$ lowers the loss by at least $\frac{1}{2\Lambda}\lVert\nabla L\rVert^2$.">

Put $\mathbf{b} = \mathbf{a} - \eta\nabla L(\mathbf{a})$, so $\mathbf{b} - \mathbf{a} = -\eta\nabla L$. The inequality gives

$L(\mathbf{b}) \leq L(\mathbf{a}) - \eta\lVert\nabla L\rVert^2 + \frac{\Lambda\eta^2}{2}\lVert\nabla L\rVert^2 = L(\mathbf{a}) - \eta\left(1 - \frac{\Lambda\eta}{2}\right)\lVert\nabla L\rVert^2$.

With $\eta = 1/\Lambda$ the bracket is $\frac{1}{2}$, so $L(\mathbf{b}) \leq L(\mathbf{a}) - \frac{1}{2\Lambda}\lVert\nabla L\rVert^2$. Any $0 \lt \eta \lt 2/\Lambda$ makes the bracket positive, so the loss decreases: the general version of the quadratic stability condition. Summing over steps also shows the gradient must eventually become small, even without convexity.

</Prove>

<Prove title="2. The noise floor of SGD" task="For $L(w) = \frac{\lambda}{2}w^2$ with noisy gradients $g_k = \lambda w_k + \epsilon_k$ (independent noise of mean 0 and variance $\sigma^2$), show that the variance of $w_k$ settles at $v = \dfrac{\eta\sigma^2}{\lambda(2 - \eta\lambda)} \approx \dfrac{\eta\sigma^2}{2\lambda}$ for small η.">

The update is $w_{k+1} = (1 - \eta\lambda)w_k - \eta\epsilon_k$. Since $\epsilon_k$ is independent of $w_k$, variances add: $\operatorname{Var}(w_{k+1}) = (1 - \eta\lambda)^2\operatorname{Var}(w_k) + \eta^2\sigma^2$.

At the steady state $v = (1 - \eta\lambda)^2v + \eta^2\sigma^2$, so $v(1 - (1 - \eta\lambda)^2) = \eta^2\sigma^2$, and $1 - (1 - \eta\lambda)^2 = \eta\lambda(2 - \eta\lambda)$. Dividing gives $v = \eta\sigma^2/(\lambda(2 - \eta\lambda))$.

The floor is proportional to the learning rate and to the gradient noise variance (which falls as 1/B with minibatches), as you measured on Day 4. A decaying learning rate drives it to zero.

</Prove>
