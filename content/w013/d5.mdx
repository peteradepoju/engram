<Step n={1} title="Overfitting" minutes={20} />

With more parameters than examples, a linear model can fit its training data exactly, noise and all. Gradient descent started from zero gets there gradually: it fits the directions with the largest singular values first (Week 7), which usually carry the real structure, and only later the small directions, where the noise has most effect. So training error falls throughout, while test error first falls and then rises.

<Step n={2} title="Early stopping" minutes={30} />

**Early stopping** keeps the weights from the step where a held-out validation error was lowest. Why does this work? For least squares started at zero, after $k$ steps of size $\eta$ the component of the weights along the $i$-th right singular vector has been fitted by a fraction $1 - (1 - \eta s_i^2)^k$ of its final value, where $s_i$ is the singular value. Ridge regression with penalty $\lambda$ fits the same component by a fraction $s_i^2/(s_i^2 + \lambda)$. Both are near 1 for large $s_i$ and near 0 for small $s_i$, and choosing $k$ roughly corresponds to choosing $\lambda \approx 1/(\eta k)$. Stopping early is an implicit penalty on the size of the weights.

In practice the stopping point is chosen on a validation set, never on the test set, or the test error stops being an honest estimate (Week 18).

<Step n={3} title="Learning-rate schedules" minutes={25} />

With stochastic gradients, a constant learning rate never settles: near the minimum the noise in each step keeps the weights moving within a cloud whose size grows with the learning rate (Week 12). The Robbins-Monro conditions say the steps should shrink, but not too fast. Common schedules:

- **Step decay**: divide the learning rate by 10 at fixed points in training.
- **Cosine decay**: $\eta_k = \tfrac{1}{2}\eta_0\left(1 + \cos(\pi k/K)\right)$, falling smoothly to zero at step $K$.
- **Warm-up**: start very small and grow linearly over the first few hundred or thousand steps. Adam's second-moment estimate is unreliable early on, and in large networks the first gradients can be huge; warm-up avoids taking big steps before either has settled.

<Step n={4} title="Weight decay and AdamW" minutes={30} />

**Weight decay** shrinks the weights a little every step: $\mathbf{w} \leftarrow (1 - \eta\lambda)\mathbf{w} - \eta\nabla L$. For plain gradient descent this is exactly the same as adding $\tfrac{\lambda}{2}\lVert\mathbf{w}\rVert^2$ to the loss, whose gradient is $\lambda\mathbf{w}$. Inside Adam the two differ. If the penalty's gradient is added to $\mathbf{g}$, it is divided by $\sqrt{\hat{\mathbf{v}}}$ like everything else: weights with large gradients are barely regularised, and weights with tiny gradients are shrunk by about the learning rate per step whatever $\lambda$ is (Day 2's sign-like behaviour). Loshchilov and Hutter (2019, today's paper) proposed **AdamW**, which applies the decay directly to the weights, outside the adaptive step, so every weight decays at the rate $\eta\lambda$.

With the penalty inside Adam, the unused weight falls to 0.56 whether $\lambda$ is 0.01 or 1, a hundredfold change with no effect, which answers the prediction: it shrinks at the same speed. <Prove title="Weight decay equals L2 for gradient descent" task="Show that one gradient descent step on $L(\mathbf{w}) + \tfrac{\lambda}{2}\lVert\mathbf{w}\rVert^2$ with step $\eta$ equals the weight-decay update $\mathbf{w} \leftarrow (1 - \eta\lambda)\mathbf{w} - \eta\nabla L$. Then explain in one sentence why the equivalence breaks for Adam.">

The gradient of the penalised loss is $\nabla L + \lambda\mathbf{w}$, so one step gives

$$
\mathbf{w} - \eta(\nabla L + \lambda\mathbf{w}) = (1 - \eta\lambda)\mathbf{w} - \eta\nabla L,
$$

which is the weight-decay update.

In Adam the penalty's gradient $\lambda\mathbf{w}$ is divided entry by entry by $\sqrt{\hat{v}_i}$, which depends on each weight's gradient history, so the effective decay rate differs between weights and is no longer $\eta\lambda$.

</Prove>

<Key title="Before you go">
<ul>
<li>Training error and test error can move in opposite directions; watch a validation set.</li>
<li>Early stopping is an implicit L2 penalty.</li>
<li>Decaying the learning rate lets SGD settle; warm-up protects the first steps.</li>
<li>Inside Adam, use decoupled weight decay (AdamW), not an L2 penalty.</li>
