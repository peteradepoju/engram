Validation picks the penalty that predicts best, and that model keeps every real input but also selects many false ones, since a slightly smaller penalty helps prediction by soaking up noise. A larger penalty selects far fewer candidates with nearly the same validation error. This is a well-known property of the lasso: the penalty that predicts best is not the one that selects best, so claims about which inputs "really" drive a neuron need more care (stability selection, or a test of each input; Week 18).

<Prove title="1. Histogram equalisation gives a uniform output" task="Let $x$ have a continuous, strictly increasing cumulative distribution $F$. Show that $r = F(x)$ is uniformly distributed on $[0, 1]$.">

For $u$ in $[0, 1]$, $P(r \le u) = P(F(x) \le u) = P(x \le F^{-1}(u))$, because $F$ is strictly increasing.

By the definition of $F$ this is $F(F^{-1}(u)) = u$. A variable with $P(r \le u) = u$ on $[0, 1]$ is uniform. This is also how computers turn uniform random numbers into any distribution, run in reverse: $x = F^{-1}(u)$.

</Prove>

<Prove title="2. When the lasso gives all zeros" task="Show that $\mathbf{w} = \mathbf{0}$ minimises $\tfrac{1}{2}\lVert A\mathbf{w} - \mathbf{y}\rVert^2 + \lambda\lVert\mathbf{w}\rVert_1$ if and only if $\lambda \ge \max_i |\mathbf{a}_i^\top\mathbf{y}|$, where $\mathbf{a}_i$ is the $i$-th column of $A$.">

The objective is convex, so $\mathbf{0}$ is a minimum exactly when $\mathbf{0}$ lies in its subgradient there.

The smooth part has gradient $A^\top(A\mathbf{0} - \mathbf{y}) = -A^\top\mathbf{y}$ at zero. The subgradient of $\lambda|w_i|$ at $w_i = 0$ is the interval $[-\lambda, \lambda]$.

So we need, for every $i$, $0 \in -\mathbf{a}_i^\top\mathbf{y} + [-\lambda, \lambda]$, that is $|\mathbf{a}_i^\top\mathbf{y}| \le \lambda$. The smallest such penalty, $\lambda_{\max} = \lVert A^\top\mathbf{y}\rVert_\infty$, is where software starts its grid of penalties, and as λ falls below it inputs enter one at a time.

</Prove>
