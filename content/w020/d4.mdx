<Step n={1} title="The divergence" minutes={25} />

The **Kullback-Leibler divergence** of $q$ from $p$ is

$$
\mathrm{KL}(p\,\|\,q) = \sum_x p(x)\log_2\frac{p(x)}{q(x)}.
$$

Its coding meaning: if outcomes come from $p$ but you use a code optimised for $q$ (codeword lengths $-\log_2 q(x)$), you pay on average $\mathrm{KL}(p\,\|\,q)$ extra bits per outcome. Kullback and Leibler (1951, today's paper) read it as the mean information per observation for telling $p$ apart from $q$: the average log-likelihood ratio, the quantity that accumulates in the odds-form updates of Week 16.

Its properties: $\mathrm{KL} \ge 0$, with equality only when $p = q$ (Gibbs' inequality); it is **not symmetric**, so it is a divergence, not a distance; and it is infinite if $q$ gives zero probability to something $p$ says can happen. That last property explains the mode-seeking of variational inference (Week 19): minimising $\mathrm{KL}(q\,\|\,p)$ forbids $q$ from putting mass where $p$ has none, while minimising $\mathrm{KL}(p\,\|\,q)$ forbids $q$ from missing anything $p$ does.

<Step n={2} title="Cross-entropy and maximum likelihood" minutes={25} />

The **cross-entropy** $H(p, q) = -\sum_x p(x)\log_2 q(x)$ is the average code length when coding $p$ with $q$, so

$$
H(p, q) = H(p) + \mathrm{KL}(p\,\|\,q).
$$

Now let $p$ be the empirical distribution of your data and $q_\theta$ a model. The average negative log-likelihood of the data under the model is exactly the cross-entropy $H(\hat{p}, q_\theta)$ (in nats if you use natural logs). Since $H(\hat{p})$ does not depend on $\theta$, **maximising the likelihood is minimising $\mathrm{KL}(\hat{p}\,\|\,q_\theta)$**: fitting a model by maximum likelihood finds the member of the family closest to the data in this direction. The "cross-entropy loss" of classifiers and language models is the same thing, and their **perplexity** is $2^{H(p, q)}$, the effective number of equally likely choices the model is left with.

<Step n={3} title="Gaussians" minutes={20} />

For two one-dimensional Gaussians the KL divergence has a closed form (in nats):

$$
\mathrm{KL}\left(\mathcal{N}(\mu_1, \sigma_1^2)\,\|\,\mathcal{N}(\mu_2, \sigma_2^2)\right) = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac{1}{2}.
$$

It appears in the ELBO of variational autoencoders (Week 16) and in comparisons of neural response distributions.

<Step n={4} title="Prediction is compression" minutes={35} />

A model that predicts each symbol from the ones before it can be used to compress a sequence: code each symbol with $-\log_2 q(x_t \mid \text{past})$ bits. Its cross-entropy per symbol is therefore its compression rate, and it can never beat the true **entropy rate** of the source; the gap is a KL divergence. This is why better next-token prediction means a better language model, and the same holds for spike trains: a model of a neuron that predicts its next bin well has captured its structure.

The context model knows that a spike is impossible in the two bins after a spike, so it is less surprised by the data, which answers the prediction. Its cross-entropy is the number of bits per bin needed to store this neuron's spikes with that model: better prediction, better compression. For this neuron the context model is essentially exact, so its cross-entropy is the train's true entropy rate.

<Prove title="Gibbs' inequality" task="Show that $\mathrm{KL}(p\,\|\,q) \ge 0$, with equality only if $p = q$, using Jensen's inequality for the concave function $\log$.">

Over the outcomes where $p(x) > 0$, $-\mathrm{KL}(p\,\|\,q) = \sum_x p(x)\log\frac{q(x)}{p(x)} = \mathbb{E}_p\left[\log\frac{q(X)}{p(X)}\right]$.

By Jensen, $\mathbb{E}_p[\log Y] \le \log\mathbb{E}_p[Y]$, and $\mathbb{E}_p\left[\frac{q(X)}{p(X)}\right] = \sum_{x: p(x) > 0} q(x) \le 1$, so $-\mathrm{KL} \le \log 1 = 0$.

Equality needs $q(x)/p(x)$ to be constant where $p > 0$ and $q$ to put no mass elsewhere, which together mean $q = p$.

</Prove>
