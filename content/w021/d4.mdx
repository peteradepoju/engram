<Step n={1} title="The matrix exponential" minutes={25} />

For one variable, $\dot{x} = ax$ has solution $x(t) = e^{at}x(0)$. For a vector, $\dot{\mathbf{x}} = A\mathbf{x}$ has solution

$$
\mathbf{x}(t) = e^{At}\mathbf{x}(0), \qquad e^{At} = I + At + \frac{(At)^2}{2!} + \frac{(At)^3}{3!} + \cdots,
$$

defined by the same power series as the ordinary exponential. Differentiating the series term by term gives $\frac{\mathrm{d}}{\mathrm{d}t}e^{At} = Ae^{At}$, so it solves the equation, and $e^{A\cdot 0} = I$ makes it start at $\mathbf{x}(0)$.

<Step n={2} title="Eigenmodes" minutes={25} />

Summing the series is rarely the way to compute $e^{At}$. If $A$ has eigenvectors $\mathbf{v}_i$ with eigenvalues $\lambda_i$ (Week 6), write $\mathbf{x}(0) = \sum_i c_i\mathbf{v}_i$. Each eigenvector evolves independently, scaled by $e^{\lambda_i t}$:

$$
\mathbf{x}(t) = \sum_i c_i e^{\lambda_i t}\mathbf{v}_i, \qquad e^{At} = V e^{\Lambda t}V^{-1}.
$$

So the eigenvalues say everything about the behaviour. If every eigenvalue has negative real part, all modes decay and the system is **stable**; a mode with time constant $-1/\text{Re}\,\lambda$ decays slowest when $\lambda$ is nearest zero. A complex pair $\lambda = a \pm i\omega$ gives oscillation at angular frequency $\omega$ inside an envelope $e^{at}$. Any eigenvalue with positive real part makes the system blow up.

<Step n={3} title="A neuron with a dendrite" minutes={25} />

Split a neuron into a soma and a dendrite, each with its own capacitance and leak, joined by a coupling conductance. The two voltages obey two coupled linear equations, and charge injected at the soma both leaks away and spreads into the dendrite. The response is a sum of two exponentials: a fast mode in which charge equalises between the compartments, and a slow mode in which the whole cell discharges. Measuring both time constants from a recording, "exponential peeling", is how Rall and others inferred the electrical structure of neurons.

<Step n={4} title="Random networks" minutes={30} />

A linear rate network, $\dot{\mathbf{x}} = -\mathbf{x} + W\mathbf{x}$, is stable when every eigenvalue of $W$ has real part below 1. For a random $W$ whose $N^2$ entries are independent with mean 0 and variance $g^2/N$, the eigenvalues fill a disc of radius $g$ centred on 0, uniformly, for large $N$: the **circular law**. So the network is stable for $g \lt 1$ and unstable for $g > 1$, when the disc pokes past 1. Rajan and Abbott (2006, today's paper) showed how separate excitatory and inhibitory populations, as in real cortex, reshape this disc. In a non-linear network, crossing $g = 1$ is where chaotic activity begins (Week 23).

With $g = 1.2$ a slice of the disc lies past 1, and those modes grow exponentially, which answers the prediction: activity explodes. Real neurons saturate, so in a non-linear network the explosion becomes sustained, irregular activity instead. Note too that even a stable network can amplify some inputs transiently before they decay if its connectivity is **non-normal** (its eigenvectors are not orthogonal), an effect that eigenvalues alone do not reveal (Murphy and Miller, 2009).

<Prove title="Eigenvectors evolve independently" task="Show that if $A\mathbf{v} = \lambda\mathbf{v}$, then $\mathbf{x}(t) = e^{\lambda t}\mathbf{v}$ solves $\dot{\mathbf{x}} = A\mathbf{x}$, and use linearity to write the general solution when $A$ has a full set of eigenvectors.">

Differentiate: $\dot{\mathbf{x}} = \lambda e^{\lambda t}\mathbf{v}$. And $A\mathbf{x} = e^{\lambda t}A\mathbf{v} = e^{\lambda t}\lambda\mathbf{v}$. The two agree, so $\mathbf{x}$ is a solution.

The equation is linear, so any sum of solutions is a solution: $\mathbf{x}(t) = \sum_i c_i e^{\lambda_i t}\mathbf{v}_i$. At $t = 0$ this is $\sum_i c_i\mathbf{v}_i$, and because the eigenvectors form a basis, the coefficients can be chosen to match any starting point: $\mathbf{c} = V^{-1}\mathbf{x}(0)$.

Each mode grows or shrinks at its own rate, never mixing with the others, which is why the eigenvalues summarise the dynamics.

</Prove>
