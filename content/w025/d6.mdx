<PyCell code={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt
  data = np.load(dataset("churchland2012_reach.npz"))
  rates, times = data["rates"].astype(float), data["times"]
  C, T, N = rates.shape
  dt = 0.01

  def preprocess(soft):
      Xs = rates / (rates.max(axis=(0, 1)) - rates.min(axis=(0, 1)) + soft + 1e-9)
      return Xs - Xs.mean(axis=0, keepdims=True)

  def rotation_r2(A, k=6):
      D = A.reshape(-1, A.shape[-1]); mu = D.mean(0)
      Vt = np.linalg.svd(D - mu, full_matrices=False)[2]
      Z = (A - mu) @ Vt[:k].T
      Zm, dZ = Z[:, :-1].reshape(-1, k), (np.diff(Z, axis=1) / dt).reshape(-1, k)
      basis = []
      for i in range(k):
          for j in range(i + 1, k):
              E = np.zeros((k, k)); E[i, j], E[j, i] = 1, -1; basis.append(E)
      G = np.stack([(Zm @ E.T).ravel() for E in basis], axis=1)
      h = np.linalg.lstsq(G, dZ.ravel(), rcond=None)[0]
      return 1 - np.sum((dZ.ravel() - G @ h) ** 2) / np.sum((dZ - dZ.mean(0)) ** 2)
  print("ready")

Two short derivations belong in an appendix, because they justify steps of the analysis.

<Prove title="1. Skew-symmetric dynamics only rotate" task="Show that if $M^\top = -M$, then the length of $\mathbf z(t)$ is constant along every solution of $\dot{\mathbf z} = M\mathbf z$, and that every eigenvalue of $M$ is purely imaginary.">

$\frac{\mathrm d}{\mathrm dt}\lVert\mathbf z\rVert^2 = 2\mathbf z^\top\dot{\mathbf z} = 2\mathbf z^\top M\mathbf z$. A number equals its transpose, so $\mathbf z^\top M\mathbf z = \mathbf z^\top M^\top\mathbf z = -\mathbf z^\top M\mathbf z$, hence it is zero, and the length is constant.

For an eigenvector $\mathbf v$ with $M\mathbf v = \lambda\mathbf v$, use the conjugate transpose: $\bar{\mathbf v}^\top M\mathbf v = \lambda\lVert\mathbf v\rVert^2$. Taking the conjugate transpose of the left side and using $M^\top = -M$ (with $M$ real) gives $\bar{\mathbf v}^\top M^\top\mathbf v = -\bar{\mathbf v}^\top M\mathbf v$, so $\bar\lambda = -\lambda$: $\lambda$ is purely imaginary.

So a skew-symmetric fit can only describe turning, which is why its R² measures how much of the population's evolution is rotation, and why the free fit's positive real parts (growth) are what it misses.

</Prove>

<Prove title="2. More components never worsen reconstruction" task="Let $V_k$ have $k$ orthonormal columns and $V_{k+1}$ add one more orthonormal column $\mathbf u$. Show that for any vector $\mathbf x$, $\lVert\mathbf x - V_{k+1}V_{k+1}^\top\mathbf x\rVert^2 \le \lVert\mathbf x - V_kV_k^\top\mathbf x\rVert^2$, which is why Day 3 needed bi-cross-validation.">

Since the columns are orthonormal, $V_{k+1}V_{k+1}^\top = V_kV_k^\top + \mathbf u\mathbf u^\top$. Write $\mathbf r = \mathbf x - V_kV_k^\top\mathbf x$, the residual with $k$ components; it is orthogonal to the columns of $V_k$.

The new residual is $\mathbf r - \mathbf u\mathbf u^\top\mathbf x = \mathbf r - (\mathbf u^\top\mathbf r)\mathbf u$, because $\mathbf u^\top\mathbf x = \mathbf u^\top\mathbf r$ ($\mathbf u$ is orthogonal to $V_k$). By Pythagoras its squared length is $\lVert\mathbf r\rVert^2 - (\mathbf u^\top\mathbf r)^2 \le \lVert\mathbf r\rVert^2$.

This holds for any $\mathbf x$, including held-out data, so reconstruction error on new conditions can only fall as components are added and cannot detect overfitting.

</Prove>
