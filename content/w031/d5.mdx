<Step n={1} title="Reliability" minutes={25} />

Mainen and Sejnowski (1995), today's paper, recorded from pyramidal neurons in slices of rat cortex. A constant current step made each neuron fire regularly, but after the first few spikes the timing drifted from trial to trial, because small amounts of internal noise (from channels, Week 29) shifted each interval a little and the shifts accumulated. The same neuron driven by a fluctuating current, frozen so that it was identical on every trial, fired spikes that lined up across trials to within about a millisecond, for the whole second. The fluctuations kept resetting the timing: each steep rise in the input forced a spike at the same moment, whatever the neuron's recent history.

<Step n={2} title="The coincidence factor" minutes={25} />

To compare two spike trains, count how many spikes in one have a partner in the other within a window $\pm\Delta$, typically 2 ms. Some coincidences happen by chance: if the second train has rate $\nu$, a Poisson train would match a given spike with probability about $2\nu\Delta$. The **coincidence factor** (Kistler and colleagues, 1997) subtracts the chance count and normalises:

$$
\Gamma = \frac{N_{coinc} - 2\nu\Delta N_1}{\frac{1}{2}(N_1 + N_2)}\cdot\frac{1}{1 - 2\nu\Delta}.
$$

$\Gamma$ is 1 for identical trains and about 0 for unrelated ones.

  import numpy as np
  import math
  import matplotlib.pyplot as plt

  def coincidence(s1, s2, T, delta=2.0):
      if len(s1) == 0 or len(s2) == 0:
          return 0.0
      n_coinc = sum(np.any(np.abs(s2 - t) <= delta) for t in s1)
      nu = len(s2) / T
      return (n_coinc - 2 * nu * delta * len(s1)) / (0.5 * (len(s1) + len(s2))) / (1 - 2 * nu * delta)

Identical trains give 1, independent ones -0.06, zero up to chance, and a 1 ms shift still counts as perfect agreement while a 3 ms shift, outside the window, scores about zero. The window defines the precision you are asking about; 2 ms is a common choice for cortical neurons.

With constant input the neuron's trials agree at only 0.09; with the frozen fluctuating input, at 0.61. That answers the prediction. The noise-free EIF matches the trials at 0.74, better than they match each other: each trial carries its own noise, which the deterministic model lacks, so the model sits closer to every trial than the trials sit to one another. The LIF, with the same leak and a threshold tuned to give the same number of spikes, scores only 0.26: without the exponential run-up, its hard threshold puts many spikes at the wrong moments.

<Step n={4} title="How good is good enough?" minutes={20} />

The comparison you just made is the logic of the spike-timing prediction competitions run by Gerstner's group around 2008 (Jolivet and colleagues), in which modellers received recordings of real neurons driven by fluctuating currents and had to predict spike times on a held-out stimulus. Scores were reported as $\Gamma$ divided by the neuron's intrinsic reliability. Simple threshold models with adaptation, of the kind this week has built, predicted a large fraction of the reliably timed spikes of cortical pyramidal cells, and did about as well as far more detailed biophysical models. The lesson is not that detail never matters, but that for the input-output behaviour of the soma, a few well-chosen variables carry most of what can be predicted.
