      return (I_train - C * dVdt)[keep].var()

  def fit_eif(C):

      edges = np.arange(-75, -43.9, 1.0); c = (edges[1:] + edges[:-1]) / 2

  def coincidence(s1, s2, T, delta=2.0):
      if len(s1) == 0 or len(s2) == 0:
          return 0.0
      n_coinc = sum(np.any(np.abs(s2 - t) <= delta) for t in s1)
      nu = len(s2) / T
      return (n_coinc - 2 * nu * delta * len(s1)) / (0.5 * (len(s1) + len(s2))) / (1 - 2 * nu * delta)

<Prove title="1. The EIF rheobase" task="For $C\dot V = I - G(V)$ with $G(V) = g_L(V - E_L) - g_L\Delta_Te^{(V - V_T)/\Delta_T}$, show that $G$ has a single maximum at $V = V_T$ and that the rheobase is $g_L(V_T - E_L - \Delta_T)$.">

$G'(V) = g_L - g_Le^{(V - V_T)/\Delta_T}$, which is zero only at $V = V_T$. $G''(V) = -\frac{g_L}{\Delta_T}e^{(V - V_T)/\Delta_T}$ is negative everywhere, so this is a maximum.

At $V_T$, $G(V_T) = g_L(V_T - E_L) - g_L\Delta_T$.

Fixed points satisfy $G(V) = I$; since $G$ has a single maximum, there are two fixed points for $I \lt G(V_T)$, one at $I = G(V_T)$ and none above. Without a fixed point the voltage runs away: the rheobase is $g_L(V_T - E_L - \Delta_T)$.

</Prove>

<Prove title="2. Shot-noise variance" task="A voltage receives jumps of size $w$ at Poisson times with rate $r$, each decaying as $we^{-t/\tau}$. Using Campbell's theorem (the variance of a sum of independent pulses is $r\int_0^\infty h(t)^2\,dt$ for pulse shape $h$), show that the variance is $\frac{\tau}{2}w^2r$.">

Here $h(t) = we^{-t/\tau}$, so $\int_0^\infty h(t)^2\,dt = w^2\int_0^\infty e^{-2t/\tau}\,dt = w^2\frac{\tau}{2}$.

Multiplying by the rate gives $\sigma^2 = \frac{\tau}{2}w^2r$.

Independent excitatory and inhibitory streams add their variances, $\frac{\tau}{2}(w_e^2r_e + w_i^2r_i)$, while their means subtract: the formula behind Day 4's balance.

</Prove>
