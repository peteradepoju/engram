The neuron fires at 67 Hz for clustered input and 23 Hz for dispersed input with the same 20 synapses. The two-layer model predicts 65 and 19 Hz. The point neuron predicts 40 Hz for both: having learned roughly equal weights for all synapses, it sees only their number. This is the decisive test. Two models that both fit average responses can be told apart by the inputs on which they disagree, and here the disagreement is about placement.

<Prove title="1. The sealed-end cable" task="For the steady cable equation $\lambda^2V'' = V$ on $0 \le x \le L$ with $V(0) = V_0$ and a sealed end, $V'(L) = 0$, show that $V(x) = V_0\cosh((L - x)/\lambda)/\cosh(L/\lambda)$, and that the input conductance is $G_\infty\tanh(L/\lambda)$, where $G_\infty$ is that of a semi-infinite cable.">

The general solution is $V = Ae^{x/\lambda} + Be^{-x/\lambda}$, or equivalently $V = C\cosh((L - x)/\lambda) + D\sinh((L - x)/\lambda)$.

The sealed end requires $V'(L) = 0$; the derivative of the sinh term at $x = L$ is $-D/\lambda$, so $D = 0$. Then $V(0) = C\cosh(L/\lambda) = V_0$ gives the stated solution.

The input current is the axial current at $x = 0$: $I = -\frac{1}{r_a}V'(0) = \frac{V_0}{r_a\lambda}\tanh(L/\lambda)$, with $r_a$ the axial resistance per unit length. For a semi-infinite cable the same calculation gives $V_0/(r_a\lambda)$, so $G_{in} = G_\infty\tanh(L/\lambda)$: a short sealed cable draws less current, and has a higher input resistance, than a long one.

</Prove>

<Prove title="2. Rall's three-halves rule" task="Show that at a branch point, two semi-infinite daughters of diameters $d_1, d_2$ present the parent with the same input conductance as a semi-infinite continuation of the parent if and only if $d_1^{3/2} + d_2^{3/2} = d_p^{3/2}$.">

A semi-infinite cable of diameter $d$ has input conductance $G_\infty = 1/R_\infty = \frac{\pi}{2\sqrt{r_mr_i}}d^{3/2}$, from Day 2.

The daughters are in parallel, so their combined conductance is $\frac{\pi}{2\sqrt{r_mr_i}}(d_1^{3/2} + d_2^{3/2})$.

This equals the continuation's $\frac{\pi}{2\sqrt{r_mr_i}}d_p^{3/2}$ exactly when $d_1^{3/2} + d_2^{3/2} = d_p^{3/2}$, since the constant is common: the branch point is then invisible to the parent.

</Prove>

<Callout kind="research">

The two-layer model treats each branch as independent. Real branches interact: a large dendritic spike in one branch depolarises its neighbours, and branches nearer the soma are weighted more. Extend the Forge neuron so that each branch's output also depends weakly on its neighbours' (for example, add 10% of the mean of the other branches' responses before the branch sigmoid), refit the independent two-layer model, and measure how much accuracy it loses. At what level of interaction would you need a third layer?
