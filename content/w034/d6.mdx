  import matplotlib.pyplot as plt
  r = np.random.default_rng(1962)
  ori = np.arange(0, 180, 22.5); n_neurons, n_trials = 20, 30
  is_tuned = np.r_[np.ones(16, bool), np.zeros(4, bool)]
  prefs = np.r_[np.linspace(0, 180, 16, endpoint=False), np.zeros(4)]
  amp = np.where(is_tuned, 12.0, 0.0)
  mean_rate = 3 + amp[:, None] * np.exp(2.0 * (np.cos(2 * np.deg2rad(ori[None, :] - prefs[:, None])) - 1))   # neurons x orientations
  z = r.normal(size=(3, len(ori), n_trials))                                                                 # shared trial factors
  loggain = 0.15 * z[0][None] + 0.25 * (np.cos(2 * np.deg2rad(prefs))[:, None, None] * z[1][None]
                                         + np.sin(2 * np.deg2rad(prefs))[:, None, None] * z[2][None])
  counts = r.poisson(mean_rate[:, :, None] * np.exp(loggain - 0.5 * (0.15**2 + 0.25**2)))                   # neurons x orientations x trials

  def osi(c):
      m = c.mean(1)
      return abs((m * np.exp(2j * np.deg2rad(ori))).sum()) / m.sum()

  def shuffle_p(c, n_shuf=300):
      real, flat = osi(c), c.ravel()
      null = [osi(r.permutation(flat).reshape(c.shape)) for _ in range(n_shuf)]
      return np.mean(np.array(null) >= real)

  pvals = np.array([shuffle_p(counts[i]) for i in range(n_neurons)])
  tuned = pvals < 0.01
  print("OSI:", np.round([osi(counts[i]) for i in range(n_neurons)], 2))
  print("p:  ", np.round(pvals, 3))
  print(f"{tuned.sum()} neurons tuned; agreement with the truth: {np.mean(tuned == is_tuned):.0%}")

<Prove title="1. The law of total variance for spike counts" task="Let $N \mid \Lambda \sim \text{Poisson}(\Lambda)$, with $\Lambda$ random, mean $\mu$ and variance $\sigma^2$. Show that $\text{Var}(N) = \mu + \sigma^2$.">

The law of total variance says $\text{Var}(N) = \mathbb E[\text{Var}(N \mid \Lambda)] + \text{Var}(\mathbb E[N \mid \Lambda])$.

For a Poisson count, both the conditional mean and variance equal $\Lambda$, so the first term is $\mathbb E[\Lambda] = \mu$ and the second is $\text{Var}(\Lambda) = \sigma^2$.

Hence $\text{Var}(N) = \mu + \sigma^2$ and the Fano factor is $1 + \sigma^2/\mu$: always at least 1, with the excess measuring variability of the underlying rate.

</Prove>

<Prove title="2. Variance of a correlated average" task="Show that the average of $N$ variables, each with variance $\sigma^2$ and pairwise correlation $\rho$, has variance $\frac{\sigma^2}{N}(1 + (N - 1)\rho)$.">

$\text{Var}\left(\frac{1}{N}\sum_i n_i\right) = \frac{1}{N^2}\sum_{i,j}\text{Cov}(n_i, n_j)$.

There are $N$ diagonal terms, each $\sigma^2$, and $N(N - 1)$ off-diagonal terms, each $\rho\sigma^2$. The sum is $N\sigma^2 + N(N - 1)\rho\sigma^2$.

Dividing by $N^2$ gives $\frac{\sigma^2}{N}(1 + (N - 1)\rho)$, which tends to $\rho\sigma^2$ as $N$ grows.

</Prove>

<Callout kind="research">

Quenching has been explained by stimulus-driven suppression of chaotic or fluctuating network dynamics, and by the stimulus pulling a multi-stable network into a single state. Build a small rate network with strong random recurrent connections (Week 23's chaotic regime), add a strong constant input at "stimulus onset", and measure the across-trial variance of the units' activity before and after. Does the input quench the variability, as Rajan, Abbott and Sompolinsky (2010) predicted for chaotic networks?
