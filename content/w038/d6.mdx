  import matplotlib.pyplot as plt
  from scipy.optimize import curve_fit
  r = np.random.default_rng(1992)
  n_cells, dirs, nph, reps = 40, np.arange(0, 360, 30), 16, 10
  contrasts = np.array([0.02, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0])
  true_simple = r.random(n_cells) < 0.5
  true_dir = r.uniform(0, 360, n_cells)
  true_ds = r.random(n_cells) < 0.4
  null_gain = np.where(true_ds, r.uniform(0, 0.2, n_cells), r.uniform(0.7, 1.0, n_cells))
  kappa = r.uniform(1.5, 4, n_cells); rmax = r.uniform(8, 25, n_cells); c50 = r.uniform(0.08, 0.4, n_cells)
  phase = np.linspace(0, 2 * np.pi, nph, endpoint=False)

  def rate(i, d, c):
      th = np.deg2rad(d - true_dir[i])
      g = np.exp(kappa[i] * (np.cos(th) - 1)) + null_gain[i] * np.exp(kappa[i] * (np.cos(th + np.pi) - 1))

      shape = np.maximum(0, np.cos(phase)) * np.pi if true_simple[i] else 1 + 0.25 * np.cos(phase)
      return 0.3 + rmax[i] * g * nr * shape / 4

  mean_dir = counts.mean(2)                                   # cells by directions

  def f1f0(x):
      F = np.fft.rfft(x)
      return 2 * np.abs(F[1]) / np.abs(F[0])

  pref_idx = mean_dir.argmax(1)
  pref_dir = dirs[pref_idx]
  f1 = np.array([f1f0(counts[i, pref_idx[i]]) for i in range(n_cells)])

<Prove title="1. Phase invariance of the energy model" task="An even filter $g_e$ and an odd filter $g_o$ in quadrature respond to a grating of phase $\phi$ with $A\cos(\phi + \delta)$ and $A\sin(\phi + \delta)$. Show that the energy does not depend on $\phi$, and that a simple cell's rectified response has F1/F0 of $\pi/2$.">

The energy is $A^2\cos^2(\phi + \delta) + A^2\sin^2(\phi + \delta) = A^2$, independent of phase.

For the simple cell, $r(\phi) = A\max(0, \cos\phi)$. Its mean over a cycle is $\frac{A}{2\pi}\int_{-\pi/2}^{\pi/2}\cos\phi\,d\phi = \frac{A}{\pi}$.

Its first Fourier coefficient has amplitude $\frac{2}{2\pi}\int_{-\pi/2}^{\pi/2} A\cos^2\phi\,d\phi = \frac{A}{2}$. So F1/F0 $= \frac{A/2}{A/\pi} = \frac{\pi}{2}$, about 1.57, which is why 1 is a natural dividing line.

</Prove>

<Prove title="2. Normalisation gives Naka-Rushton with contrast-invariant tuning" task="With $E_i = c^2\hat E_i$ for every cell in the pool, show that $R_i = E_i/(\sigma^2 + \sum_j E_j)$ equals a fixed tuning term times $c^2/(c_{50}^2 + c^2)$, and find $c_{50}$.">

Substituting, $R_i = \frac{c^2\hat E_i}{\sigma^2 + c^2\sum_j \hat E_j}$.

Divide numerator and denominator by $\sum_j \hat E_j$: $R_i = \frac{\hat E_i}{\sum_j \hat E_j}\cdot\frac{c^2}{\sigma^2/\sum_j\hat E_j + c^2}$.

The first factor depends on the cell's tuning but not on contrast; the second is a Naka-Rushton function with exponent 2 and $c_{50} = \sigma/\sqrt{\sum_j \hat E_j}$. Contrast multiplies the whole tuning curve by the same factor, so its shape, and its width, cannot change.

</Prove>
