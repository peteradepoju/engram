<Prove title="1. Steady state and time scale of a single-rate learner" task="For $x_{n+1} = Ax_n + B(f - x_n)$ with constant $f$, find the steady state and show that the distance from it shrinks by a factor $A - B$ each trial.">

At steady state $x^* = Ax^* + B(f - x^*)$, so $x^*(1 - A + B) = Bf$ and $x^* = \frac{B}{1 - A + B}f$, which is less than $f$ whenever $A \lt 1$.

Subtracting the steady-state equation from the update: $x_{n+1} - x^* = (A - B)(x_n - x^*)$.

So the error from steady state shrinks geometrically by $A - B$ per trial, with time constant about $-1/\ln(A - B)$ trials. Fast learning (large $B$) and good retention (A near 1) pull in opposite directions on this factor, which is one motivation for having two processes.

</Prove>

<Prove title="2. The one-step LQR gain" task="For a scalar system $x' = ax + bu$ and cost $q x'^2 + r u^2$, find the optimal $u$ and check it against the Riccati formula with $S = q$.">

The cost is $q(ax + bu)^2 + ru^2$. Setting its derivative with respect to $u$ to zero: $2qb(ax + bu) + 2ru = 0$.

Solving, $u = -\frac{qab}{r + qb^2}\,x = -Kx$ with $K = \frac{qab}{r + qb^2}$.

The Riccati formula gives $K = (r + bSb)^{-1}bSa$ with $S = q$, the same. The gain grows with $q$ (caring more about the error) and shrinks with $r$ (caring more about effort), and the full recursion repeats this one step backward through time, carrying the future cost in $S$.

</Prove>
