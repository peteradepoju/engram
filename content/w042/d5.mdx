<Step n={1} title="The third factor" minutes={20} />

A three-factor rule has the form

$$
\dot w_{ij} = \eta\, M(t)\, e_{ij}(t), \qquad \tau_e\,\dot e_{ij} = -e_{ij} + H(\text{pre}_j, \text{post}_i),
$$

where $H$ is a Hebbian or STDP term built from the two local factors and $M$ is the third factor, a signal broadcast to many synapses. The eligibility trace $e_{ij}$ remembers recent coincidences for a time $\tau_e$; nothing changes until $M$ arrives. Frémaux and Gerstner (2016) review the candidates for $M$: dopamine for reward and reward prediction error, acetylcholine and noradrenaline for novelty and surprise, and serotonin.

The evidence for traces is now direct. In striatal spines, Yagishita and colleagues (2014) paired glutamate uncaging with action potentials and then released dopamine. The spines enlarged only when dopamine arrived between about 0.3 and 2 seconds after the pairing, which is the window an eligibility trace predicts. He and colleagues (2015) found similar traces in visual cortex, where noradrenaline converted a trace into potentiation and serotonin into depression.

Izhikevich (2007) posed the problem sharply. If a reward follows the activity that caused it by a second or more, many unrelated synapses will have been active in between. How does the right one get the credit? His answer was that unrelated coincidences are as likely to be followed by reward as not, so their changes average to nothing, while the causal synapse is reliably followed by reward. Let us check.

solution={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt

  def distal(tau_e, eta=0.002, T=50000, seed=2007):
      r = np.random.default_rng(seed)
      N, delay = 100, 100
      w = np.full(N, 1.0); e = np.zeros(N); pending = []; DA = 0.0; DAbar = 0.1
      for t in range(T):
          pairs = r.random(N) < 0.005                  # random coincidences
          e *= np.exp(-1 / tau_e); e[pairs] += 1       # update the traces
          if pairs[0]:
              pending.append(t + delay + int(r.integers(0, 100)))
          DA *= np.exp(-1 / 20)
          while pending and pending[0] <= t:
              DA += 1; pending.pop(0)
          DAbar += (DA - DAbar) / 5000                 # slow running mean of dopamine
          w = np.clip(w + eta * (DA - DAbar) * e, 0, 10)
      return w

  w_long, w_short = distal(200), distal(10)
  print(f"trace 200 steps: synapse 0 {w_long[0]:.2f}, others mean {w_long[1:].mean():.2f}, max {w_long[1:].max():.2f}")
  print(f"trace 10 steps:  synapse 0 {w_short[0]:.2f}, others mean {w_short[1:].mean():.2f}, max {w_short[1:].max():.2f}")
  plt.bar(range(100), w_long); plt.xlabel("synapse"); plt.ylabel("final weight"); plt.show()

With a trace that lasts about as long as the reward delay, synapse 0 grows to about 4.9 while the other 99 synapses stay near 1, none above 1.9. Every synapse was tagged equally often; only synapse 0's tags were reliably still present when dopamine arrived. Subtracting the running mean of dopamine is what keeps the unrelated synapses still: for them, dopamine above and below its mean is equally likely while a tag is present, and the changes cancel. With a 10-step trace the tag has gone long before the reward, and synapse 0 is no different from the rest.

<Step n={3} title="Learning from perturbation" minutes={35} />

Can a three-factor rule do more than credit one synapse? Consider a neuron whose output is $y = \mathbf w\cdot\mathbf x + \xi$, where $\xi$ is a little random noise, the neuron's own exploration. After each trial a reward $R$ is broadcast. The rule

$$
\Delta\mathbf w = \eta\,(R - \bar R)\,\xi\,\mathbf x
$$

has a Hebbian part, $\xi\mathbf x$, the correlation between input and the neuron's deviation from its usual output, and a third factor $R - \bar R$. It is node perturbation, and it is a version of the REINFORCE algorithm (Williams, 1992).

<Derivation>
<div>

The reward depends on the weights through the noisy output. Write the expected reward as $J(\mathbf w) = \mathbb E[R(y)]$ with $y = \mathbf w\cdot\mathbf x + \xi$ and $\xi \sim \mathcal N(0, \sigma^2)$.

</div>
<div>

For small $\sigma$, expand $R(y) \approx R(\mathbf w\cdot\mathbf x) + R'(\mathbf w\cdot\mathbf x)\,\xi$. Then $\mathbb E[R\,\xi\,\mathbf x] \approx R'\,\mathbb E[\xi^2]\,\mathbf x = \sigma^2 R'\,\mathbf x$, because $\mathbb E[\xi] = 0$.

</div>
<div>

The gradient of the reward with respect to the weights is $\partial R/\partial\mathbf w = R'\,\mathbf x$. So $\mathbb E[\Delta\mathbf w] \approx \eta\sigma^2\,\partial J/\partial\mathbf w$: on average the rule climbs the reward gradient.

</div>
<div>

Subtracting any $\bar R$ that does not depend on $\xi$ leaves the mean unchanged, since $\mathbb E[\bar R\,\xi\,\mathbf x] = 0$, but it can greatly reduce the variance of each update.

</div>
</Derivation>

solution={String.raw`
  r = np.random.default_rng(2016)
  D = 10
  w_star = r.normal(size=D)

  def rm_hebb(baseline=True, trials=3000, eta=0.002, sig=0.5):
      w = np.zeros(D); Rbar = 0.0; errs = []
      for k in range(trials):
          x = r.normal(size=D); xi = sig * r.normal()
          y = w @ x + xi
          R = 20.0 - (y - w_star @ x) ** 2
          M = R - Rbar if baseline else R
          w += eta * M * xi * x
          Rbar += 0.05 * (R - Rbar)
          errs.append(np.sum((w - w_star) ** 2))
      return w, np.array(errs)

  _, err_b = rm_hebb(True)
  _, err_nb = rm_hebb(False)
  print(f"squared weight error after learning: with baseline {np.mean(err_b[-200:]):.3f}, without {np.mean(err_nb[-200:]):.3f}")
  plt.semilogy(err_b, label="R minus baseline"); plt.semilogy(err_nb, label="raw R"); plt.xlabel("trial"); plt.ylabel("|w - w*|²"); plt.legend(); plt.show()

With a baseline the squared weight error falls from about 7 to about 0.02: a neuron that only ever hears one number per trial has learned all ten weights. Without a baseline the mean update is the same but every update is multiplied by a reward of about 20, so the noise is huge and the weights jitter around the target with an error near 2. The reward was offset by 20 on purpose: real rewards have no natural zero, and a rule that depends on where zero is would be fragile.

<Step n={4} title="Links to reinforcement learning" minutes={15} />

The baseline in the last cell is a prediction of reward, and $R - \bar R$ is a reward prediction error. That is precisely the signal Schultz, Dayan and Montague (1997) found in midbrain dopamine neurons, which you will study in Week 44. Three-factor rules are therefore the synaptic half of a theory of reinforcement learning in the brain: dopamine supplies the error, eligibility traces supply the memory of which synapses were involved.

The same logic appears in modern machine learning. Policy-gradient methods use REINFORCE with a learned baseline, and recent biologically motivated alternatives to backpropagation, such as e-prop (Bellec and colleagues, 2020), combine local eligibility traces with a broadcast learning signal to train recurrent spiking networks.

<Callout kind="think">

Node perturbation works, but its updates are noisy, and the noise grows with the number of neurons sharing one reward signal. With a million neurons and one scalar reward, how long would learning take? This scaling problem is one reason researchers look for richer third factors, such as signals that differ across neuron groups or carry vector errors.

</Callout>
