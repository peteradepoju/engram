With weights matched to the target, the downstream cell has a single field whose peak lies about 6 cm from it: the grids of all four modules peak together only there, and the threshold keeps only that coincidence. With random weights the cell has three fields scattered across the arena, because different subsets of grids happen to align in several places. The coarse modules matter: without them, the fine grids' periodicity would give the downstream cell repeating fields. The same idea, in reverse, is the Day 2 modular code: what the grid code makes unique, a summing cell can pick out.

**Part B: detecting replay.** Twenty place cells have fields in order along a linear track. During a sharp-wave ripple, each fires once. In a forward replay event the spikes follow the field order, compressed so that the whole track takes about 200 ms, with timing jitter of 15 ms; in a control event the order is random. The rank-order test (Lee and Wilson, 2002) correlates each cell's field order with its spike time and compares the correlation with 1,000 shuffles of cell identity.

solution={String.raw`
  N_c = 20; order = np.arange(N_c)

  def make_event(kind, step=0.01, jitter=0.015):
      base = {"forward": order, "reverse": order[::-1], "random": r.permutation(N_c)}[kind] * step
      return base + jitter * r.normal(size=N_c)

  def rank_corr(a, b):
      ra, rb = np.argsort(np.argsort(a)), np.argsort(np.argsort(b))
      return np.corrcoef(ra, rb)[0, 1]

  def rank_test(times, n=1000):
      rho = rank_corr(order, times)
      null = np.array([rank_corr(r.permutation(N_c), times) for _ in range(n)])
      return rho, np.mean(np.abs(null) >= abs(rho))

  rho_f, p_f = rank_test(make_event("forward"))
  rho_r, p_r = rank_test(make_event("reverse"))
  rho_c, p_c = rank_test(make_event("random"))
  for nm, (rho, p) in {"forward": (rho_f, p_f), "reverse": (rho_r, p_r), "random": (rho_c, p_c)}.items():
      print(f"{nm:8s} rho = {rho:+.2f}, p = {p:.3f}")

The forward event has a rank correlation of about 0.98 and none of 1,000 shuffles comes close; the reversed event is equally significant with the opposite sign. Reverse replay is real: Foster and Wilson (2006) found it in awake rats pausing at the end of a run, and it has been linked to propagating reward information backwards along a path. The random event gives a small correlation with p near 0.5. Real events are harder: fewer cells fire, some fire more than once, and the number of candidate events tested is large, so the false positive rate must be controlled across all of them.

<Prove title="1. Spatial information of an ideal place cell" task="A cell fires at rate $\lambda$ in a fraction $f$ of the arena and is silent elsewhere, with uniform occupancy. Show that its Skaggs information is $\log_2(1/f)$ bits per spike.">

The mean rate is $\bar\lambda = f\lambda$. In the field, $\lambda_i/\bar\lambda = 1/f$; outside, the rate is zero and contributes nothing.

So $I = \sum_{\text{field}} p_i \frac{1}{f}\log_2\frac{1}{f} = f \cdot \frac{1}{f}\log_2\frac{1}{f} = \log_2\frac{1}{f}$.

A field covering 1/16 of the arena carries 4 bits per spike. Smaller fields carry more information per spike, but the cell fires less often, so its information per second, $\bar\lambda\,I = f\lambda\log_2(1/f)$, is largest for intermediate field sizes.

</Prove>

<Prove title="2. Random walk error" task="Position is estimated by summing $n$ velocity steps, each with independent error of variance $\sigma^2 \Delta t^2$. Show that the standard deviation of the position error after time $t = n\Delta t$ is $\sigma\sqrt{\Delta t\, t}$.">

The position error is the sum of $n$ independent errors $\epsilon_k \Delta t$ with variance $\sigma^2\Delta t^2$ each.

Variances of independent terms add: $\mathrm{Var} = n\sigma^2\Delta t^2 = (t/\Delta t)\sigma^2\Delta t^2 = \sigma^2\Delta t\, t$.

The standard deviation is $\sigma\sqrt{\Delta t\,t}$, which grows like $\sqrt t$. Halving the velocity noise halves the error at every time, but no amount of improvement stops the growth: only an external reference, a landmark, can.

</Prove>
