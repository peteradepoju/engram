**Part A: facilitation stabilises the bump.** Take Day 1's ring with connection heterogeneity (random errors of 0.5/N), which makes the bump drift towards a few preferred positions as in Week 43. Now give every synapse a facilitation variable $u_j$ for its presynaptic neuron, which rises with that neuron's activity and decays to a baseline $U = 0.3$ with $\tau_F = 20$ time units:

$$
\dot u_j = \frac{U - u_j}{\tau_F} + U(1 - u_j)\,r_j,
$$

and scale each neuron's outgoing effect by $u_j / U$. Synapses from neurons inside the bump become stronger, which should make the bump stickier. Start 40 bumps at evenly spaced angles and measure how far each has drifted after 6,000 steps.

Without facilitation, heterogeneity makes the bumps drift a median of 0.44 rad, and some by more than 1.5 rad, towards the network's few preferred positions. With facilitation the median drift falls to 0.15 rad. The neurons in the bump strengthen their own outgoing synapses, which deepens the valley the bump sits in and makes the small biases from heterogeneity too weak to move it. Itskov, Hansel and Tsodyks (2011) proposed exactly this mechanism, and it is an example of synaptic and persistent mechanisms working together rather than as alternatives.

**Part B: slots or resources, by model comparison.** Day 3 fitted a mixture to errors at each set size separately. A stronger test fits each model's full predictions across set sizes at once. The **slot model** has two parameters, the number of slots $K$ and the precision $\sigma$, and predicts a guess rate of $\max(0, 1 - K/N)$ with constant $\sigma$. The **resource model** has one parameter, $\sigma_1$, and predicts no guessing with $\sigma_N = \sigma_1\sqrt N$. Fit both by maximum likelihood to data from each model, and let BIC decide.

  from scipy.optimize import minimize
  g = np.random.default_rng(2012)
  wrap = lambda x: np.angle(np.exp(1j * x))
  sd1 = np.deg2rad(15); sizes = [1, 2, 4, 6]
  def gen_slots(N, n=400, K=3):
      st = g.random(n) < min(1, K / N)
      return np.where(st, sd1 * g.normal(size=n), g.uniform(-np.pi, np.pi, n))
  def gen_resource(N, n=400):
      return wrap(sd1 * np.sqrt(N) * g.normal(size=n))
  datasets = {"slot data": {N: gen_slots(N) for N in sizes}, "resource data": {N: gen_resource(N) for N in sizes}}
  normal = lambda e, s: np.exp(-e ** 2 / (2 * s ** 2)) / np.sqrt(2 * np.pi * s ** 2)

  def nll_slots(p, data):
      K, s = p
      total = 0.0
      for N, e in data.items():
          gp = max(0.0, 1 - K / N)
          total -= np.sum(np.log((1 - gp) * normal(e, s) + gp / (2 * np.pi)))
      return total

  def nll_resource(p, data):
      s1 = p[0]
      return -sum(np.sum(np.log(normal(e, s1 * np.sqrt(N)) + 1e-300)) for N, e in data.items())

  bic = {}

      n = sum(len(v) for v in data.values())
      fs = minimize(nll_slots, [2.5, 0.3], args=(data,), method="Nelder-Mead")

For slot data, the slot model wins by over 1,000 BIC units and recovers about 3.1 slots and a precision near 15 degrees; for resource data, the resource model wins by about 300 units and recovers a precision of 15 degrees for a single item. Fitting all set sizes together uses each model's full prediction, how guessing and precision should change with $N$, instead of describing each set size separately, which is why the comparison is so decisive here. With real data the margins are far smaller and depend on which variants of each model are included.

<Prove title="1. Diffusion of a bump" task="A bump's centre moves by independent small steps of variance $\epsilon^2$ per unit time. Show that the variance after time $t$ is $\epsilon^2 t$ and that the standard deviation doubles when the delay quadruples.">

After $t$ unit steps the displacement is a sum of $t$ independent steps, each of variance $\epsilon^2$.

Variances of independent terms add, so the variance is $t\epsilon^2$, linear in $t$.

The standard deviation is $\epsilon\sqrt t$; multiplying $t$ by 4 multiplies it by $\sqrt 4 = 2$. Behavioural errors in delayed-response tasks often follow this pattern over a few seconds, which is one argument for drift-based models of working memory.

</Prove>

<Prove title="2. Separable dichotomies of pure selectivity" task="Neurons respond linearly to three binary variables $a, b, c$. Show that the XOR dichotomy, conditions with $a \oplus b = 1$ against the rest, cannot be read out linearly, whatever the number of neurons.">

Every neuron's response is $w_0 + w_a a + w_b b + w_c c$, so any linear readout of the population is also of the form $v_0 + v_a a + v_b b + v_c c$, and the readout must be positive exactly when $a \oplus b = 1$.

Consider $c = 0$ and the four combinations of $a, b$. We need $v_0 \lt 0$ (for $a = b = 0$), $v_0 + v_a \gt 0$, $v_0 + v_b \gt 0$, and $v_0 + v_a + v_b \lt 0$.

Adding the middle two gives $2v_0 + v_a + v_b \gt 0$, but adding the first and last gives $2v_0 + v_a + v_b \lt 0$, a contradiction. More neurons do not help because they only add more linear functions of the same three variables. A nonlinearity, such as the threshold in mixed selectivity, is needed.

</Prove>
