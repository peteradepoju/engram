<Step n={1} title="Variability as a feature" minutes={20} />

Suppose neuron $i$ fires $r_i$ spikes, Poisson with mean $g f_i(s)$, where $f_i$ is its tuning curve and $g$ a gain set by contrast or reliability. Then

$$
\log p(\mathbf r \mid s) = \sum_i r_i \log f_i(s) - g\sum_i f_i(s) + \text{terms without } s.
$$

If tuning curves tile the stimulus space densely, $\sum_i f_i(s)$ is nearly constant in $s$, and with a flat prior the posterior is

$$
p(s \mid \mathbf r) \propto \exp\Big(\sum_i r_i \log f_i(s)\Big) = \exp\big(\mathbf h(s)\cdot\mathbf r\big),
$$

linear in the spike counts through the fixed kernels $h_i(s) = \log f_i(s)$. Ma and colleagues called this a **probabilistic population code**. Two consequences follow. Higher gain means more spikes and a narrower posterior: the gain encodes certainty. And because the log-posterior is linear in $\mathbf r$, adding two populations' spike counts adds their log-likelihoods, which multiplies the likelihoods: exactly Bayesian cue combination (Week 16).

solution={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt
  r = np.random.default_rng(2006)
  pref = np.linspace(-90, 90, 61); s_grid = np.linspace(-45, 45, 901); width = 15.0

  def tuning(s, g):
      return g * np.exp(-(s - pref) ** 2 / (2 * width ** 2)) + 0.1

  logF = -(s_grid[:, None] - pref[None]) ** 2 / (2 * width ** 2)     # log f_i(s) up to a constant

  def posterior(rs):
      lp = logF @ rs
      lp -= lp.max()
      p = np.exp(lp)
      return p / p.sum()

  def mean_sd(p):
      m = (p * s_grid).sum()
      return m, np.sqrt((p * (s_grid - m) ** 2).sum())

  rs = r.poisson(tuning(5.0, 4))
  p = posterior(rs)
  print(f"posterior mean {mean_sd(p)[0]:.2f}, sd {mean_sd(p)[1]:.2f} (true stimulus 5)")
  fig, ax = plt.subplots(1, 2, figsize=(9, 3.4)); ax[0].bar(pref, rs, width=2.5); ax[0].set_xlabel("preferred stimulus")
  ax[1].plot(s_grid, p); ax[1].axvline(5, color="k", ls=":"); ax[1].set_xlabel("stimulus"); plt.show()

On this trial the posterior peaks at 3.0 with a standard deviation of about 1.9: the true stimulus, 5, lies just over one standard deviation away, as it should a fair fraction of the time. The posterior is computed from a fixed linear readout of spike counts followed by exponentiation and normalisation, operations that are easy for neurons: the weights $h_i(s)$ never change, only the activity does.

On every one of 300 trials, the posterior from the summed spike counts is identical, to numerical precision, to the normalised product of the two separate posteriors. The combined posterior's width, 1.18, equals the optimal $1/\sqrt{1/\sigma_1^2 + 1/\sigma_2^2}$, and it is narrower than either cue alone. The more reliable population automatically gets more weight because it contributes more spikes. No reliability-dependent weights had to be computed or learned, which is the main appeal of the scheme.

<Callout kind="warning">

The exactness depends on assumptions: Poisson-like variability (strictly, an exponential family with linear sufficient statistics), tuning curves whose shape does not change with gain, and tuning that tiles the space so that the summed rate is constant. Real responses often violate them, for example when contrast changes tuning width or when noise is correlated (Week 35). Fetsch, Pouget, DeAngelis and Angelaki (2012) found that MSTd neurons combine visual and vestibular cues with weights that change with reliability, as the theory requires, but not by simple addition. Alternative proposals, in which neural activity represents samples from the posterior (Orbán, Berkes, Fiser and Lengyel, 2016), make different predictions about variability.

</Callout>
