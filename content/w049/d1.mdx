<Step n={1} title="Graphs and their measures" minutes={20} />

A network of $N$ nodes is described by an adjacency matrix $A$, with $A_{ij} = 1$ if nodes $i$ and $j$ are linked. Three measures recur:

- **degree** $k_i = \sum_j A_{ij}$, the number of links of node $i$;
- **clustering** $C_i$, the fraction of pairs of $i$'s neighbours that are linked to each other, $C_i = \frac{(A^3)_{ii}/2}{k_i(k_i - 1)/2}$, averaged over nodes;
- **characteristic path length** $L$, the average number of steps on the shortest path between pairs of nodes.

A regular lattice has high clustering and long paths; a random graph has low clustering and short paths. Watts and Strogatz found that most of the path shortening happens after only a few random shortcuts are added, while clustering survives far longer. Networks with high clustering and short paths are called **small worlds**. In brains, clustering is thought to support specialised local processing and short paths fast integration across the whole.

  r = np.random.default_rng(1998)

  def ws(N=200, k=6, p=0.0):
      A = np.zeros((N, N), bool)
      for i in range(N):
          for j in range(1, k // 2 + 1):
              A[i, (i + j) % N] = A[(i + j) % N, i] = True
      for i in range(N):
          for j in range(1, k // 2 + 1):
              t = (i + j) % N
              if r.random() < p and A[i, t]:
                  n = r.choice(np.where(~A[i] & (np.arange(N) != i))[0])
                  A[i, t] = A[t, i] = False; A[i, n] = A[n, i] = True
      return A

  def clustering(A):
      A = A.astype(float); k = A.sum(1); tri = np.diag(A @ A @ A) / 2
      return np.mean(np.where(k > 1, tri / (k * (k - 1) / 2), 0))

  def pathlen(A):
      D = shortest_path(A.astype(float), unweighted=True)
      return D[np.isfinite(D) & (D > 0)].mean()

  res = {}

      print(f"p = {p:5.3f}: C/C0 = {res[p][0]:.3f}, L/L0 = {res[p][1]:.3f}")

Rewiring 0.1% of links changes nothing visible. At 1%, clustering is still 97% of the lattice's but the average path has halved; at 10%, paths are 29% of the lattice's while clustering is still 81%. Only when nearly all links are random does clustering collapse, to 4%. The asymmetry is the whole point: each shortcut shortens many paths at once, because every path that can use it benefits, while it removes only a few triangles.

<Step n={3} title="Random-graph baselines" minutes={25} />

A measured network's clustering and path length mean little on their own; they must be compared with random graphs that have the same number of nodes and links. For an Erdős-Rényi random graph with mean degree $k$, theory gives $C_\text{rand} \approx k/N$ and $L_\text{rand} \approx \ln N/\ln k$. The **small-world index** (Humphries, Gurney and Prescott, 2006) is

$$
\sigma = \frac{C/C_\text{rand}}{L/L_\text{rand}},
$$

and values well above 1 indicate a small world.

The fully rewired graph matches the random-graph formulas closely: clustering 0.031 against $k/N = 0.030$ and path length 3.1 against 3.0. The network with 5% rewiring has a small-world index of 10, the random graph 0.7. But notice the lattice: its index is 3.5, above the conventional threshold, because its enormous clustering more than compensates for its long paths. This is one reason the index is criticised: a value above 1 does not distinguish a small world from a lattice, and Telesford and colleagues (2011) proposed comparing clustering with a lattice and path length with a random graph instead.

<Step n={4} title="What small-worldness means" minutes={25} />

Watts and Strogatz computed $C$ and $L$ for the neural network of C. elegans (282 neurons at the time), the western US power grid and a film actor collaboration graph, and all three were small worlds. Since then, small-world structure has been reported for anatomical and functional brain networks at every scale (Bullmore and Sporns, 2009; tomorrow's paper). Two cautions temper the finding. First, almost any sparse network with some local structure is a small world by the standard index, so the label alone says little (Papo, Zanin, Martínez and Buldú, 2016). Second, functional networks built by thresholding correlations are biased towards high clustering, because correlation is partly transitive: if A correlates with B and B with C, A tends to correlate with C (Zalesky, Fornito and Bullmore, 2012). The more informative questions concern which nodes are hubs, how the network divides into modules, and how much wiring the structure costs, which are tomorrow's subject.
