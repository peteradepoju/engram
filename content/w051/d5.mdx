<Step n={1} title="Set up and the logic of controls" minutes={20} />

A control asks whether a simpler or different explanation could produce the same result. Each of today's four controls targets one way the conclusion could be wrong:

1. **Perseveration.** The action kernel contains the previous choice; its rivals do not. Give all of them a one-trial previous-choice term and compare again.
2. **Falsification.** Simulate each fitted model and check which reproduces the signature that distinguishes them: repeating a choice after an error.
3. **Recovery.** Simulate mice from each model with fitted parameters and check that the comparison recovers the model that generated them.
4. **Slow drift.** Mice's biases may wander over tens of trials for reasons unrelated to the blocks. Roy and colleagues (2021) built a method to track such drifting weights across training. Here a cheaper test suffices: add a slow kernel and see whether the fast one survives.

The setup cell rebuilds Day 3's models and refits the three models with a prior to every mouse.

  def kernel(x, alpha, sess_ids):
      out = np.zeros(len(x))
      for s in np.unique(sess_ids):
          k = sess_ids == s
          out[k] = lfilter([alpha], [1, -(1 - alpha)], np.r_[0, x[k][:-1]])
      return out

  def lag1(x, sess_ids):
      out = np.r_[0, x[:-1]]; out[np.r_[True, sess_ids[1:] != sess_ids[:-1]]] = 0
      return out

  def bayes_prior(side, sess_ids, h=0.02):
      out = np.zeros(len(side))
      for s in np.unique(sess_ids):
          b = np.array([0.5, 0.5])
          for t in np.flatnonzero(sess_ids == s):
              pr = 0.8 * b[0] + 0.2 * b[1]; out[t] = np.log(pr / (1 - pr))
              b = b * (np.array([0.8, 0.2]) if side[t] > 0 else np.array([0.2, 0.8])); b = b / b.sum()
              b = np.array([(1 - h) * b[0] + h * b[1], (1 - h) * b[1] + h * b[0]])
      return out

  prior_bayes = bayes_prior(side, sess)
  models = ["bayes", "stimulus", "action"]
  x0 = {"bayes": [3, 0, 1], "stimulus": [3, 0, 1, 0.2], "action": [3, 0, 1, 0.2]}

  def logit(model, p, k, actions):
      """Logit of P(right) on the trials selected by k, given the +-1 actions that drive an action kernel."""
      z = p[0] * f_c[k] + p[1]
      if model == "bayes":

      return z + p[2] * kernel(x, p[3], sess[k])

  def fit(model, k, y_all, extra=None):
      """Fit a model to the trials selected by k, with choices y_all (0/1, all trials of k). Returns (params, max log-lik)."""
      use = ok[k]; y = y_all[use]; a = np.where(y_all >= 0, 2 * y_all - 1, 0.0)
      n_extra = 0 if extra is None else 1
      def f(p):
          z = logit(model, p, k, a)
          if extra is not None:

          return np.sum(np.logaddexp(0, z) - y * z)
      res = minimize(f, x0[model] + [0.0] * n_extra, method="L-BFGS-B", bounds=bounds[model] + [(-20, 20)] * n_extra)

With a previous-choice term in every model, the action kernel still has the most evidence for 17 of the 18 mice, and it leads the stimulus kernel by about 1,060 nats summed over mice (down from about 1,830 without the term). So one-trial perseveration explains part of the advantage, but less than half of it. The rest comes from the longer reach of the kernel: the mice's choices are pulled by their actions two, three and five trials back, in proportion, and a single extra weight on the last choice cannot mimic that. The one mouse that now prefers the Bayesian model shows that the comparison is sensitive to individual differences, not fixed in favour of the action kernel.

This is the clearest result of the week. The real mice repeat after rewards (+0.67) and after errors (+0.50, positive for 17 of 18). Simulated action-kernel mice reproduce both, with +0.64 and +0.55, positive after errors for all 18. Simulated Bayesian and stimulus-kernel mice repeat after rewards but *switch* after errors, with weights of −0.17 and −0.20, and only 0 and 2 of 18 show a positive weight. That answers the prediction, and it falsifies both rivals in the sense of Week 50: with their best-fitting parameters, they produce the opposite of a robust feature of the data. No amount of parameter tuning would fix this, because switching after errors is built into any model that learns from where the stimulus was.

Add a second, slow kernel of past choices with a fixed rate of 0.02 (a memory of about 50 trials) to the action model, and see whether the fast kernel keeps its weight.

The slow kernel earns its parameter for 13 of 18 mice, with a median gain of 6.9 nats, so there is a slower component in the choices: the flat tail of Day 2's history kernel. But it does not replace the fast kernel, which keeps a median 73% of its weight, and whose rate rises from 0.21 to 0.28 now that it no longer has to account for the slow tail. The block tracking is not slow drift in disguise. A fuller analysis would let weights drift freely, as Roy and colleagues' PsyTrack does, and ask whether the drift lines up with the blocks; the Research callout in tomorrow's lesson suggests how.
