Three choices could have shaped the result: the contrast transform $\tanh(5c)/\tanh(5)$, the decision to fit all trials including the unbiased first 90 of each session, and the Bayesian observer's switch rate $h = 0.02$. A conclusion worth reporting should survive sensible alternatives. The setup cell rebuilds the models of Days 3 and 5.

<PyCell code={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt
  from scipy.optimize import minimize
  from scipy.signal import lfilter
  from scipy.special import erf
  d = np.load(dataset("ibl_biased.npz"))
  mouse, session = d["mouse"].astype(int), d["session"].astype(int)
  contrast, choice, reward = d["contrast"].astype(float), d["choice"].astype(float), d["reward"].astype(int)
  p_left, rt = d["p_left"].astype(float).round(2), d["rt"].astype(float)
  ok = (choice >= 0) & d["included"] & np.isfinite(rt)
  sess = 10 * mouse + session
  c_pm = np.where(choice >= 0, 2 * choice - 1, 0.0)
  side = np.where(contrast != 0, np.sign(contrast), np.where(reward == 1, c_pm, -c_pm))

  def kernel(x, alpha, sess_ids):
      out = np.zeros(len(x))
      for s in np.unique(sess_ids):
          k = sess_ids == s
          out[k] = lfilter([alpha], [1, -(1 - alpha)], np.r_[0, x[k][:-1]])
      return out

  def bayes_prior(side, sess_ids, h=0.02):
      out = np.zeros(len(side))
      for s in np.unique(sess_ids):
          b = np.array([0.5, 0.5])
          for t in np.flatnonzero(sess_ids == s):
              pr = 0.8 * b[0] + 0.2 * b[1]; out[t] = np.log(pr / (1 - pr))
              b = b * (np.array([0.8, 0.2]) if side[t] > 0 else np.array([0.2, 0.8])); b = b / b.sum()
              b = np.array([(1 - h) * b[0] + h * b[1], (1 - h) * b[1] + h * b[0]])
      return out

  models = ["bayes", "stimulus", "action"]
  x0 = {"bayes": [3, 0, 1], "stimulus": [3, 0, 1, 0.2], "action": [3, 0, 1, 0.2]}
  bounds = {"bayes": [(-20, 20)] * 3, "stimulus": [(-20, 20)] * 3 + [(0.01, 1)], "action": [(-20, 20)] * 3 + [(0.01, 1)]}
  prior_cache = {0.02: bayes_prior(side, sess)}

  def compare(scale=5, use=None, h=0.02):
      """-BIC/2 of the three models for every mouse, under a contrast transform tanh(scale c), a trial mask and a switch rate h."""
      use = ok if use is None else ok & use
      fc = np.tanh(scale * contrast) / np.tanh(scale)
      if h not in prior_cache:
          prior_cache[h] = bayes_prior(side, sess, h)
      pb = prior_cache[h]
      lme = np.zeros((18, 3))
      for m in range(18):
          k = mouse == m; u = use[k]; y = choice[k][u]; n = u.sum()
          for j, mod in enumerate(models):
              def f(p):
                  z = p[0] * fc[k] + p[1]
                  if mod == "bayes":
                      z = z + p[2] * pb[k]
                  else:
                      z = z + p[2] * kernel(side[k] if mod == "stimulus" else c_pm[k], p[3], sess[k])
                  z = z[u]
                  return np.sum(np.logaddexp(0, z) - y * z)
              res = minimize(f, x0[mod], method="L-BFGS-B", bounds=bounds[mod])
              lme[m, j] = -res.fun - len(x0[mod]) * np.log(n) / 2
      return lme
  print("ready")

Fitting only the biased blocks shrinks the lead, as it should with fewer trials, but leaves the winner unchanged. The same holds for the Bayesian observer's switch rate: with $h = 0.01$ or $h = 0.04$ instead of 0.02 the observer still trails the action kernel by about 1,940 to 2,010 nats (you can check this with `compare(h=0.04)`, which takes a few seconds). The conclusion does not hinge on these choices.

Two short derivations belong in an appendix, because they justify steps of the analysis.

<Prove title="1. The noise of a leaky average" task="Let $s_t$ be independent with mean $\mu$ and variance $v$, and $\pi_t = (1 - \alpha)\pi_{t-1} + \alpha s_{t-1}$. Show that in the steady state $\pi_t$ has mean $\mu$ and variance $\frac{\alpha}{2 - \alpha}v$, and that after a change in $\mu$ the mean approaches its new value as $(1-\alpha)^n$.">

Unrolling the recursion, $\pi_t = \alpha\sum_{j \ge 0}(1 - \alpha)^j s_{t-1-j}$.

The weights sum to $\alpha \cdot \frac{1}{1 - (1 - \alpha)} = 1$, so the mean is $\mu$.

The terms are independent, so the variance is $v\,\alpha^2\sum_j (1 - \alpha)^{2j} = v\,\frac{\alpha^2}{1 - (1 - \alpha)^2} = v\,\frac{\alpha^2}{\alpha(2 - \alpha)} = \frac{\alpha}{2 - \alpha}v$.

If the mean changes from $\mu_0$ to $\mu_1$ at trial 0, then $\mathbb E[\pi_n] - \mu_1 = (1 - \alpha)\left(\mathbb E[\pi_{n-1}] - \mu_1\right)$, so the gap shrinks by a factor $1 - \alpha$ each trial. A small $\alpha$ gives low variance and a slow approach: the trade-off of Day 4.

</Prove>

<Prove title="2. Why a stimulus learner must switch after errors" task="Show that on a trial where the mouse chose $a_t = \pm 1$ and was wrong, a stimulus kernel moves away from the chosen side, while an action kernel moves towards it.">

An error means the stimulus was on the other side: $s_t = -a_t$.

The stimulus kernel updates as $\pi_{t+1} = (1 - \alpha)\pi_t + \alpha s_t = (1 - \alpha)\pi_t - \alpha a_t$, so relative to simple decay it moves by $-\alpha a_t$, away from the chosen side, making a repeat less likely.

The action kernel updates as $\pi_{t+1} = (1 - \alpha)\pi_t + \alpha a_t$, moving towards the chosen side whatever the outcome.

So any positive weight on the stimulus kernel predicts switching after errors, which is why no parameter setting could make the stimulus kernel reproduce the mice's repetition after errors on Day 5.

</Prove>
