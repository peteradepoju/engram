<Prove title="C1. The steady state of a conductance-based compartment" task="A compartment with capacitance $C$ obeys $C\dot V = \sum_j g_j(E_j - V)$ for constant conductances $g_j \gt 0$. Show that $V$ relaxes exponentially to $V_\infty = \frac{\sum_j g_jE_j}{\sum_j g_j}$ with time constant $C/\sum_j g_j$, and explain why adding a conductance with $E_j = V_\infty$ shortens the time constant without moving the steady state.">

Write $g = \sum_j g_j$. Then $C\dot V = \sum_j g_jE_j - gV = g(V_\infty - V)$ with $V_\infty = \sum_j g_jE_j/g$.

This is linear with solution $V(t) = V_\infty + (V(0) - V_\infty)e^{-tg/C}$: exponential relaxation with time constant $C/g$.

$V_\infty$ is a weighted average of the reversal potentials, with weights $g_j/g$. A new conductance with $E_j$ equal to the current $V_\infty$ adds $g_jV_\infty$ to the numerator and $g_j$ to the denominator, leaving the average unchanged, but it increases $g$, so the time constant $C/g$ falls and every other input's effect is divided by a larger total conductance. This is shunting, as in Problem B1.

</Prove>

<Prove title="C2. Rescorla-Wagner as an exponential average" task="With $V_{n+1} = V_n + \alpha(r_n - V_n)$ and $V_0 = 0$, show that $V_n = \alpha\sum_{k=0}^{n-1}(1 - \alpha)^{n-1-k}r_k$, and that if the $r_k$ are independent with mean $p$, then $\mathbb E[V_n] = p\left(1 - (1 - \alpha)^n\right)$.">

Rewrite the update as $V_{n+1} = (1 - \alpha)V_n + \alpha r_n$. By induction: it holds for $n = 1$ ($V_1 = \alpha r_0$), and if it holds for $n$, then $V_{n+1} = (1 - \alpha)\alpha\sum_{k=0}^{n-1}(1 - \alpha)^{n-1-k}r_k + \alpha r_n = \alpha\sum_{k=0}^{n}(1 - \alpha)^{n-k}r_k$.

Taking expectations, $\mathbb E[V_n] = \alpha p\sum_{j=0}^{n-1}(1 - \alpha)^j = \alpha p\,\frac{1 - (1 - \alpha)^n}{\alpha} = p\left(1 - (1 - \alpha)^n\right)$.

So the prediction approaches the reward probability geometrically, at a rate set by $\alpha$, and it weights recent outcomes more: the same leaky average as the action kernel of Week 51, and the reason Problem B4's learning rate can be read from the speed of the approach.

</Prove>
