With 25 training trials the linear model is more accurate (test MSE 0.64 against 0.89): ten neighbours out of 25 average over most of the input space, so the nearest-neighbour model is too smooth and too noisy at once. With 2,000 trials the order reverses decisively, 0.29 against 0.49, because the nearest-neighbour model captures the interaction between the two signals, which the linear model cannot represent at all. The linear coefficients, about 1.0 for the first signal and 0 for the second, are perfectly interpretable and describe a world in which the second signal does not matter, while in fact its effect is as large as the first's for many trials, with a sign that depends on the first. Breiman's point exactly: an interpretable model that predicts badly can tell a confident and wrong story. The fix is not always to give up interpretation, but to check it against a flexible model's predictions, and here to add the interaction term the residuals point to.

<Prove title="1. Why the chosen model's training error is optimistic" task="For any fixed hypothesis $h$, show that $\mathbb E[\hat R_n(h)] = R(h)$. Then show that for the empirical risk minimiser $\hat h$ over a class $\mathcal H$, $\mathbb E[\hat R_n(\hat h)] \le \min_{h \in \mathcal H} R(h)$.">

For fixed $h$, $\hat R_n(h)$ is an average of $n$ independent copies of $\ell(y, h(\mathbf x))$, each with expectation $R(h)$, so $\mathbb E[\hat R_n(h)] = R(h)$: the training error of a model chosen *before* seeing the data is unbiased.

The minimiser satisfies $\hat R_n(\hat h) \le \hat R_n(h)$ for every $h \in \mathcal H$, on every dataset. Taking expectations, $\mathbb E[\hat R_n(\hat h)] \le \mathbb E[\hat R_n(h)] = R(h)$ for every $h$, so $\mathbb E[\hat R_n(\hat h)] \le \min_h R(h)$.

And since $\hat h \in \mathcal H$, its expected risk is at least $\min_h R(h)$. So on average the minimiser's training error is below the best achievable risk, which is in turn below the minimiser's own risk: the training error is optimistic twice over. The same argument applies to a validation error used for selection.

</Prove>

<Prove title="2. Bias and variance of a one-dimensional ridge estimate" task="With $y_i = wx_i + \varepsilon_i$, fixed inputs, noise variance $\sigma^2$ and $S = \sum_i x_i^2$, the ridge estimate is $\hat w = \frac{\sum_i x_iy_i}{S + \lambda}$. Show that its bias is $-\frac{\lambda}{S + \lambda}w$ and its variance $\frac{\sigma^2 S}{(S + \lambda)^2}$, and that the mean squared error is minimised at $\lambda = \sigma^2/w^2$.">

$\mathbb E[\hat w] = \frac{\sum_i x_i\,wx_i}{S + \lambda} = \frac{S}{S + \lambda}w$, so the bias is $\frac{S}{S + \lambda}w - w = -\frac{\lambda}{S + \lambda}w$.

$\text{Var}(\hat w) = \frac{\sum_i x_i^2\sigma^2}{(S + \lambda)^2} = \frac{\sigma^2S}{(S + \lambda)^2}$.

The mean squared error is $\frac{\lambda^2w^2 + \sigma^2S}{(S + \lambda)^2}$. Its derivative with respect to $\lambda$ has numerator $2\lambda w^2(S + \lambda) - 2(\lambda^2w^2 + \sigma^2S) = 2S(\lambda w^2 - \sigma^2)$, which is zero at $\lambda = \sigma^2/w^2$: penalise more when the noise is large relative to the effect. Any $\lambda$ between zero and twice this value beats least squares, so some shrinkage always helps.

</Prove>
