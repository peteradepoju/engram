<Step n={1} title="Corners make zeros" minutes={20} />

The lasso (least absolute shrinkage and selection operator) minimises

$$
\frac{1}{2n}\lVert\mathbf y - X\mathbf w\rVert^2 + \lambda\lVert\mathbf w\rVert_1, \qquad \lVert\mathbf w\rVert_1 = \sum_j |w_j|.
$$

Equivalently, it minimises the squared error subject to $\lVert\mathbf w\rVert_1 \le t$ for some budget $t$. The constraint region is a diamond in two dimensions, a cross-polytope in many, with corners on the axes. The elliptical contours of the squared error usually first touch such a region at a corner, where some weights are exactly zero. Ridge's constraint is a sphere, with no corners, so its solutions almost never lie on an axis.

<Step n={2} title="Soft thresholding" minutes={25} />

<Derivation title="The lasso for an orthonormal design">
<div>

Suppose the columns of $X$ are orthonormal after scaling, $X^\top X = nI$. Then the objective separates into one problem per weight: minimise $\frac12(w_j - z_j)^2 + \lambda|w_j|$, where $z_j = \mathbf x_j^\top\mathbf y/n$ is the least-squares estimate.

</div>
<div>

For $w_j \gt 0$ the derivative is $w_j - z_j + \lambda$, zero at $w_j = z_j - \lambda$, valid only if $z_j \gt \lambda$. Symmetrically $w_j = z_j + \lambda$ if $z_j \lt -\lambda$. At $w_j = 0$ the absolute value has a kink, and zero is optimal whenever $|z_j| \le \lambda$, because the subgradient of $\lambda|w|$ at zero covers $[-\lambda, \lambda]$.

</div>
<div>

Together: $\hat w_j = S_\lambda(z_j) = \text{sign}(z_j)\max(|z_j| - \lambda, 0)$, the **soft-thresholding** operator. Small estimates are set to zero and large ones are pulled towards zero by $\lambda$. Ridge would instead scale every estimate by the same factor, and best-subset selection would keep large estimates unchanged (hard thresholding).

</div>
</Derivation>

With $\lambda = 0.2$, the least-squares estimates 1.02, 0.49, 0.14, −0.03 and −0.31 become 0.82, 0.29, 0, 0 and −0.11: the two small ones vanish, and every survivor is pulled 0.2 towards zero. The plot shows the three rules side by side. Hard thresholding is discontinuous, so a tiny change in the data can make a weight jump in or out; ridge is smooth but never selects; soft thresholding selects and is continuous, which is why the lasso is stable enough to compute and analyse. Its cost is visible too: the weights it keeps are biased towards zero, by exactly $\lambda$ in this case.

<Step n={3} title="Coordinate descent" minutes={35} />

With correlated columns the weights no longer separate, but a simple algorithm works: cycle through the weights, and set each to its optimal value with the others held fixed. For standardised columns, that optimum is again a soft threshold, of the correlation between column $j$ and the **partial residual** $\mathbf y - \sum_{k \ne j}\mathbf x_kw_k$. Each update can only lower the objective, which is convex, so the cycle converges to the solution.

With $\lambda = 0.1$, 41 of the 50 weights are exactly zero. The five true inputs (indices 0, 3, 7, 12 and 20) are all selected, with values 0.93, −0.66, 0.53, 0.37 and −0.27 against true values of 1.0, −0.8, 0.6, 0.5 and −0.4: all shrunk towards zero. Four other weights are non-zero but tiny, at most 0.01. The optimality check passes: every zero weight has a gradient of at most 0.098, below $\lambda$, so no single weight could profitably leave zero. Feature 1, built to be correlated with feature 0, is correctly left out here, but correlated features are the lasso's weak point, as the next lesson shows.

At small penalties all five true inputs are found, but with many false ones: 27 of 45 at $\lambda = 0.02$, 13 at 0.05, 3 at 0.1. At $\lambda = 0.2$ the lasso finds all five and almost nothing else (0.07 false inputs on average), which answers the prediction: with 100 trials and well-separated effects, near-perfect recovery is possible. Raise the penalty further to 0.35 and the weakest true input (−0.4) starts to be missed. Recovery this clean depends on strong effects, uncorrelated inputs and a well-chosen $\lambda$; in real data, with correlated inputs and a penalty chosen for prediction rather than selection (usually smaller), expect several false positives. <Key title="Before you go">
<ul>
<li>An L1 penalty selects variables as well as shrinking them.</li>
<li>For orthonormal designs the lasso is soft thresholding of least-squares estimates.</li>
<li>Coordinate descent solves the lasso with simple soft-threshold updates, checked by the KKT conditions.</li>
<li>Selection trades false positives against missed inputs as λ changes; no single λ is perfect.</li>
</ul>
</Key>
