<Step n={1} title="Softmax and its loss" minutes={20} />

With $K$ classes, give each class $k$ a weight vector $\mathbf w_k$ and a score $z_k = \mathbf w_k^\top\mathbf x$. The **softmax** turns scores into probabilities:

$$
p_k(\mathbf x) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}.
$$

The probabilities are positive and sum to one, the largest score wins, and adding the same constant to every score changes nothing, which is why one class's weights can be fixed at zero (for $K = 2$ this recovers logistic regression). The loss is again the negative log-likelihood, the cross-entropy $-\sum_i \log p_{y_i}(\mathbf x_i)$, and with one-hot labels $Y$ and probabilities $P$ (both $n \times K$) its gradient with respect to the weight matrix $W$ ($p \times K$) is

$$
\nabla_W L = X^\top(P - Y).
$$

Bridle, today's paper, argued in 1990 that networks with this output layer should be read as estimating class probabilities, and gave the function the name it still has.

solution={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt
  from scipy.optimize import minimize
  r = np.random.default_rng(562)
  K, N = 8, 80
  dirs = np.arange(K) * 2 * np.pi / K
  pref = r.uniform(0, 2 * np.pi, N); depth = r.uniform(0.2, 1.0, N)

  def trials(n, g):
      lab = g.integers(0, K, n)
      rates = 10 * (1 + depth * np.cos(dirs[lab][:, None] - pref))
      return g.poisson(rates * 0.2).astype(float), lab

  X_tr, lab_tr = trials(320, r); X_te, lab_te = trials(2000, r)
  mu, sd = X_tr.mean(0), X_tr.std(0) + 1e-9
  A_tr, A_te = np.c_[np.ones(320), (X_tr - mu) / sd], np.c_[np.ones(2000), (X_te - mu) / sd]
  Y_tr = np.eye(K)[lab_tr]

  def softmax(Z):
      Z = Z - Z.max(axis=1, keepdims=True)
      E = np.exp(Z)
      return E / E.sum(axis=1, keepdims=True)

  def loss_grad(w_flat, lam=1e-2):
      W = w_flat.reshape(A_tr.shape[1], K)
      P = softmax(A_tr @ W)
      loss = -np.mean(np.log(P[np.arange(len(lab_tr)), lab_tr])) + 0.5 * lam * np.sum(W[1:] ** 2)
      G = A_tr.T @ (P - Y_tr) / len(lab_tr)
      G[1:] += lam * W[1:]
      return loss, G.ravel()

  res = minimize(loss_grad, np.zeros(A_tr.shape[1] * K), jac=True, method="L-BFGS-B")
  W = res.x.reshape(A_tr.shape[1], K)
  P_te = softmax(A_te @ W)
  acc_soft = np.mean(P_te.argmax(1) == lab_te)
  print(f"converged: {res.success}; test accuracy {acc_soft:.3f} (chance {1 / K:.3f})")

L-BFGS converges in a fraction of a second and the decoder is right on 80% of test trials, against 12.5% by chance, from 200 ms of activity in 80 neurons. Nothing beyond the gradient formula was needed: the optimiser handles step sizes, and the small penalty keeps the weights finite even though eight classes in 81 dimensions could otherwise be separated almost perfectly on 320 trials.

<Step n={3} title="One-vs-rest" minutes={20} />

A common shortcut trains $K$ separate binary classifiers, each separating one class from all the others, and picks the class whose classifier is most confident. It works, but its $K$ probabilities are not fitted jointly, so they need not sum to one.

Eight separate binary classifiers manage only 68.6% against softmax's 80%. Each one-vs-rest problem is unbalanced (one class against seven) and harder than it looks, and the eight classifiers are never calibrated against one another, so taking the largest of their probabilities is a poor way to choose. Their probabilities sum to 0.98 on average but anywhere from 0.02 to 2.54 on individual trials, so they cannot be read as a distribution over directions. Softmax fits all classes jointly, which is why it is the standard choice.

<Step n={4} title="The structure of mistakes" minutes={30} />

Accuracy treats every mistake alike, but the classes here have an order around a circle. A **confusion matrix**, counting how often each true class is decoded as each predicted class, shows where the errors go. And since the softmax gives a full probability distribution over directions, you can also decode a continuous angle, by taking the direction of the probability-weighted average of the eight unit vectors, which matters when real reaches are not restricted to the eight trained directions.

Every single error falls on a neighbouring direction, 45 degrees away; the decoder never confuses opposite or distant directions. That answers the prediction, and it reflects the population code: cosine tuning makes nearby directions produce similar activity, so the classes inherit the circle's geometry. The probabilities carry this structure too. For reaches in arbitrary directions, picking the most probable of the eight trained directions gives a mean error of 18 degrees, but the probability-weighted average direction gives 11.8 degrees, interpolating between the trained directions in proportion to the evidence. Accuracy alone would have hidden both facts.
