<Step n={1} title="Fast readout of object identity" minutes={20} />

Hung and colleagues, today's paper, recorded multi-unit activity at a few hundred sites in inferior temporal cortex while monkeys viewed 77 images in 8 categories, and trained linear classifiers on the spike counts in short windows. Category could be read out above chance from about 100 ms after image onset, from windows as short as 12.5 ms, and with accuracy growing steadily with the number of sites. The point was not that a monkey uses this classifier, but that the information is available in a form a single downstream layer of neurons could read.

<Step n={2} title="Decoding over time" minutes={35} />

A simulated population of 100 neurons responds to images from 4 categories. After a latency of about 80 ms, each category evokes its own pattern of rate changes. Spike counts are taken in 25 ms bins from −50 to 300 ms. In each bin, train and test a classifier with five-fold cross-validation.

The classifier is **shrinkage LDA**: LDA with its pooled covariance pulled towards a multiple of the identity, $\hat\Sigma_\gamma = (1 - \gamma)\hat\Sigma + \gamma\frac{\text{tr}\hat\Sigma}{D}I$. With 100 neurons and a few hundred trials, the raw covariance is too noisy to invert; shrinkage, a cousin of ridge, fixes that in closed form, which makes it the standard decoder for this kind of analysis.

  times = np.arange(-50, 300, 25)                       # bin starts (ms)
  patterns = r.normal(size=(C, N)) * 0.2                # category-specific modulation
  def time_course(t):
      return np.clip((t - 80) / 50, 0, 1)                # responses begin about 80 ms after onset
  cats = r.integers(0, C, n_trials)
  shared = r.normal(size=(n_trials, len(times), 1)) * 0.3
  log_rate = np.log(2.0) + time_course(times)[None, :, None] * patterns[cats][:, None, :] + shared
  counts = r.poisson(np.exp(log_rate)).astype(float)    # trials x bins x neurons

  def shrink_lda_fit(X, y, gamma):
      classes = np.arange(C)
      mus = np.array([X[y == k].mean(0) for k in classes])
      Xc = X - mus[y]
      S = Xc.T @ Xc / (len(y) - C)
      S = (1 - gamma) * S + gamma * np.trace(S) / X.shape[1] * np.eye(X.shape[1])
      W = np.linalg.solve(S, mus.T)                     # D x C
      b = -0.5 * np.sum(W * mus.T, axis=0)
      return W, b

  def cv_acc(X, y, gamma=0.2, K=5):
      folds = np.array_split(np.arange(len(y)), K); correct = 0
      for te in folds:
          tr = np.setdiff1d(np.arange(len(y)), te)
          W, b = shrink_lda_fit(X[tr], y[tr], gamma)
          correct += np.sum((X[te] @ W + b).argmax(1) == y[te])
      return correct / len(y)

  acc_t = np.array([cv_acc(counts[:, j, :], cats) for j in range(len(times))])
  for t_, a in zip(times, acc_t):
      if t_ % 50 == 0: print(f"{t_:4d} ms: accuracy {a:.2f}")

Before the image appears, accuracy sits at chance (0.25), as it must: a decoder that beat chance there would signal a bug or a leak. It begins to rise in the bin starting at 75 ms, reaches 0.39 at 100 ms and 0.86 by 150 ms, and stays above 0.8, all from 25 ms of spikes in 100 neurons. The rise lags the true response onset of 80 ms because the category signal starts small; the latency at which decoding first becomes significant always depends on signal size, trial numbers and bin width, so comparisons of latency between areas need matched analyses.

Two neurons decode at 41% (chance 25%), five at 62%, ten at 74%, and 50 almost perfectly, from the late window. Each neuron adds a little independent information, so accuracy climbs steadily and then saturates near 100%. In this simulation the shared fluctuation in excitability does not limit decoding much, because it shifts all neurons together, along a direction the shrinkage LDA can learn to ignore. Correlations that mimic the signal itself, information-limiting correlations, would cap accuracy below 100% however many neurons were added, as the figure shows.

<Step n={4} title="Does the code change over time?" minutes={25} />

Accuracy in each bin says *whether* category is decodable, not *how* it is coded. Train in one bin and test in every other: if the code is stable, a decoder trained early works late; if it changes, accuracy falls off the diagonal. King and Dehaene called this the **temporal generalisation** method. Simulate a population whose pattern for each category switches between an early and a late phase, and compare.

In the dynamic code, a decoder trained at 100 ms works at 100 ms (0.42, early in the response) and one trained at 250 ms works at 250 ms (0.81), but the early decoder tested at 250 ms is at chance (0.26), although the category information is fully present there. That answers the prediction: when the code changes, decoders do not transfer. The matrix shows two blocks along the diagonal, one per coding phase, with little between them. A stable code would instead fill a square from response onset onwards. The distinction matters for theories of working memory and of how cortex transforms information, and time-resolved decoding alone cannot see it.
