<Prove title="1. The logistic loss is convex" task="For $L(\mathbf w) = -\sum_i [y_i\log\sigma(\mathbf x_i^\top\mathbf w) + (1 - y_i)\log(1 - \sigma(\mathbf x_i^\top\mathbf w))]$, show that the Hessian is $X^\top SX$ with $S = \text{diag}(p_i(1 - p_i))$, and that it is positive semi-definite.">

The gradient is $\sum_i (p_i - y_i)\mathbf x_i$ with $p_i = \sigma(\mathbf x_i^\top\mathbf w)$. Differentiating again, $\partial p_i/\partial\mathbf w = p_i(1 - p_i)\mathbf x_i$, so the Hessian is $\sum_i p_i(1 - p_i)\mathbf x_i\mathbf x_i^\top = X^\top SX$.

For any vector $\mathbf v$, $\mathbf v^\top X^\top SX\mathbf v = \sum_i p_i(1 - p_i)(\mathbf x_i^\top\mathbf v)^2 \ge 0$, since every $p_i(1 - p_i) \gt 0$.

So the loss is convex: every local minimum is global, and gradient descent or Newton's method cannot get stuck. (Strict convexity can fail, as on separable data, where the minimum is not attained at all.)

</Prove>

<Prove title="2. LDA's log-odds are linear" task="If $\mathbf x \mid y = k \sim \mathcal N(\boldsymbol\mu_k, \Sigma)$ with a shared $\Sigma$ and prior $\pi_k$, show that $\log\frac{P(y = 1 \mid \mathbf x)}{P(y = 0 \mid \mathbf x)} = \mathbf w^\top\mathbf x + b$ with $\mathbf w = \Sigma^{-1}(\boldsymbol\mu_1 - \boldsymbol\mu_0)$.">

By Bayes' rule the log-odds is $\log\frac{\pi_1}{\pi_0} + \log\mathcal N(\mathbf x; \boldsymbol\mu_1, \Sigma) - \log\mathcal N(\mathbf x; \boldsymbol\mu_0, \Sigma)$.

The normalising constants are equal and cancel. The exponents give $-\frac12(\mathbf x - \boldsymbol\mu_1)^\top\Sigma^{-1}(\mathbf x - \boldsymbol\mu_1) + \frac12(\mathbf x - \boldsymbol\mu_0)^\top\Sigma^{-1}(\mathbf x - \boldsymbol\mu_0)$.

Expanding, the $\mathbf x^\top\Sigma^{-1}\mathbf x$ terms cancel, leaving $(\boldsymbol\mu_1 - \boldsymbol\mu_0)^\top\Sigma^{-1}\mathbf x - \frac12\boldsymbol\mu_1^\top\Sigma^{-1}\boldsymbol\mu_1 + \frac12\boldsymbol\mu_0^\top\Sigma^{-1}\boldsymbol\mu_0$.

So the log-odds is linear in $\mathbf x$, exactly the form of logistic regression: LDA and logistic regression share a model family and differ in how they fit it, by class densities or by the conditional likelihood.

</Prove>
