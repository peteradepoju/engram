The linear decoder is no better than chance (43%, against 50%): an ellipse centred on the mean cannot be approximated by a single straight cut, and the linear model's errors are slightly worse than guessing because of its arbitrary tilt. The Gaussian-kernel SVM, with γ chosen inside each outer fold, reaches 78%, and the random-feature decoder 72%, with a fixed γ and only 300 features. The nested scheme matters: each outer accuracy was computed on trials that played no part in choosing γ, so 78% is an honest estimate of how the whole procedure, including the choice, would do on new data. Six irrelevant neurons hold both nonlinear decoders back; Week 58's trees, which select inputs as they go, cope better with that.

**Part B: support vectors bound the leave-one-out error.** If a training example is not a support vector, removing it leaves the SVM unchanged, so it is still classified correctly when left out. Only support vectors can become errors, so the leave-one-out error is at most the fraction of support vectors. Check this on 80 crescent-shaped examples for several values of C.

For every C the leave-one-out error is well below the fraction of support vectors: 0.075 against 0.60 at $C = 0.3$, and 0.062 against 0.31 at $C = 10$. The bound holds, as the argument guarantees, but it is loose, because most support vectors are still classified correctly when left out. Its value lies elsewhere: it shows why sparse solutions generalise, and it costs nothing to compute. Large C gives fewer support vectors and so a tighter bound, but not a lower error, a reminder that a bound is a guarantee, not an estimate.

<Prove title="1. The quadratic kernel as an inner product" task="For $\mathbf x, \mathbf z \in \mathbb R^d$, show that $(1 + \mathbf x^\top\mathbf z)^2 = \phi(\mathbf x)^\top\phi(\mathbf z)$ for a feature map $\phi$ containing 1, $\sqrt2x_i$, $x_i^2$ and $\sqrt2x_ix_j$ for $i \lt j$.">

Expand: $(1 + \mathbf x^\top\mathbf z)^2 = 1 + 2\sum_i x_iz_i + \left(\sum_i x_iz_i\right)^2$.

The square is $\sum_i x_i^2z_i^2 + 2\sum_{i \lt j}x_ix_jz_iz_j$.

Each term is a product of the same function of $\mathbf x$ and of $\mathbf z$: $1 \cdot 1$, $(\sqrt2x_i)(\sqrt2z_i)$, $(x_i^2)(z_i^2)$ and $(\sqrt2x_ix_j)(\sqrt2z_iz_j)$. Summing them is exactly $\phi(\mathbf x)^\top\phi(\mathbf z)$, with $1 + d + d + d(d-1)/2 = \binom{d+2}{2}$ features.

</Prove>

<Prove title="2. Ridge weights lie in the span of the inputs" task="Show that the minimiser of $\lVert\mathbf y - X\mathbf w\rVert^2 + \lambda\lVert\mathbf w\rVert^2$ with $\lambda \gt 0$ has the form $\mathbf w = X^\top\boldsymbol\alpha$, so that predictions need only inner products between inputs.">

Write any $\mathbf w$ as $\mathbf w = X^\top\boldsymbol\alpha + \mathbf w_\perp$, where $\mathbf w_\perp$ is orthogonal to every row of $X$.

Then $X\mathbf w = XX^\top\boldsymbol\alpha$ does not depend on $\mathbf w_\perp$, so the squared-error term does not either.

The penalty is $\lVert X^\top\boldsymbol\alpha\rVert^2 + \lVert\mathbf w_\perp\rVert^2$ by Pythagoras, which is reduced by setting $\mathbf w_\perp = \mathbf 0$. So the minimiser lies in the span of the inputs, $\mathbf w = X^\top\boldsymbol\alpha$.

Predictions are $\mathbf w^\top\mathbf x = \sum_i\alpha_i\mathbf x_i^\top\mathbf x$: only inner products appear. The same argument, applied in a kernel's feature space with any loss, is the representer theorem.

</Prove>
