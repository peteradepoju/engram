<Step n={1} title="Why averaging helps" minutes={20} />

Average $B$ predictors, each with variance $\sigma^2$ and pairwise correlation $\rho$. The variance of the average is

$$
\rho\sigma^2 + \frac{1 - \rho}{B}\sigma^2.
$$

As $B$ grows, the second term vanishes but the first stays: averaging can remove only the part of the variance that the predictors do not share. Bagging produces trees that are correlated, because they are grown on overlapping resamples of the same data and tend to make the same strong splits. Breiman's random forests, today's paper, reduce $\rho$ by letting each split consider only $m$ randomly chosen features, so that strong features cannot dominate every tree.

<Step n={2} title="Bagging trees" minutes={30} />

The problem: predict an animal's choice (left or right) from 12 neurons on each trial. Four of them carry the choice signal, partly through an interaction between two of them, and they are correlated with each other; the other eight are noise. The setup cell provides the tree code, with an option to choose a random subset of features at each split.

<PyCell code={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt
  r = np.random.default_rng(583)
  P = 12

  def trials(n, g):
      shared = g.normal(size=(n, 1))
      sig = 0.7 * shared + g.normal(size=(n, 4))                    # four correlated choice-related neurons
      z = 1.5 * sig[:, 0] + 1.0 * sig[:, 1] - 1.0 * sig[:, 2] * sig[:, 3]   # with a nonlinear interaction
      y = (g.random(n) < 1 / (1 + np.exp(-2 * z))).astype(int)
      return np.c_[sig, g.normal(size=(n, P - 4))], y

  def gini_counts(c):
      n = c.sum(-1, keepdims=True); return 1 - np.sum((c / np.maximum(n, 1)) ** 2, axis=-1)

  def best_split(X, y, feats):
      best = (None, None, np.inf); n = len(y)
      for j in feats:
          o = np.argsort(X[:, j]); xs, ys = X[o, j], y[o]
          left = np.cumsum(np.eye(2)[ys], axis=0)[:-1]; right = left[-1] + np.eye(2)[ys[-1]] - left
          nl = np.arange(1, n); imp = (nl * gini_counts(left) + (n - nl) * gini_counts(right)) / n
          imp = np.where(xs[1:] > xs[:-1], imp, np.inf); i = int(np.argmin(imp))
          if imp[i] < best[2]: best = (j, (xs[i] + xs[i + 1]) / 2, imp[i])
      return best

  def grow(X, y, g, mtry=None, min_leaf=2):
      counts = np.bincount(y, minlength=2)
      if len(y) < 2 * min_leaf or counts.max() == len(y): return ("leaf", counts[1] / counts.sum())
      feats = range(X.shape[1]) if mtry is None else g.choice(X.shape[1], mtry, replace=False)
      j, t, imp = best_split(X, y, feats)
      if j is None: return ("leaf", counts[1] / counts.sum())
      m = X[:, j] <= t
      if m.all() or (~m).all(): return ("leaf", counts[1] / counts.sum())
      return ("node", j, t, grow(X[m], y[m], g, mtry, min_leaf), grow(X[~m], y[~m], g, mtry, min_leaf))

  def predict(tree, X):
      if tree[0] == "leaf": return np.full(len(X), tree[1])
      _, j, t, L, R = tree; m = X[:, j] <= t; out = np.empty(len(X))
      out[m], out[~m] = predict(L, X[m]), predict(R, X[~m]); return out

  X, y = trials(250, r); X_te, y_te = trials(2000, r)
  acc = lambda p, y_: np.mean((p > 0.5) == (y_ == 1))
  print("ready: 250 training trials of 12 neurons, 2,000 test trials")

A single deep tree, grown on a bootstrap resample, is right on 73% of test trials. Averaging 3 trees gives 76.5%, 10 trees 79.5% and 30 trees 80.5%: a gain of more than seven points from averaging alone, with no change to the trees themselves. The gains shrink as trees are added, because the variance that the trees share does not average away, exactly as the formula of Step 1 says.

Considering only 6 of the 12 features at each split lowers the average correlation between trees from 0.47 to 0.39, and the 30-tree forest reaches 81.2% against bagging's 80.5%. The gain is modest here because the strong neurons are themselves correlated, so a split on any of them carries similar information; with more features and a few dominant ones, random feature selection usually helps more. The number of features per split, $m$, is the forest's main tuning parameter: smaller $m$ gives less correlated but individually weaker trees.

<Step n={4} title="Out-of-bag error" minutes={25} />

Each bootstrap resample leaves out about a third of the training examples (the chance that a given example is never drawn in $n$ draws is $(1 - 1/n)^n \approx e^{-1} \approx 0.37$). Predicting each training example using only the trees that did not see it gives an **out-of-bag** estimate of test accuracy, without a separate validation set.

Each tree left out 36.5% of the training trials, close to the predicted $e^{-1} \approx 37\%$. Predicting each trial from only the trees that never saw it gives an out-of-bag accuracy of 82.0%, against 80.9% on 2,000 genuinely new trials.
