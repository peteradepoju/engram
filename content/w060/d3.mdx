<Step n={1} title="More clusters always fit better" minutes={15} />

With $k = n$ clusters, every point is its own centre and the distortion is zero; a mixture with a component per point has infinite likelihood (Day 2). In between, the best achievable objective improves monotonically with $k$. The popular **elbow method**, looking for a bend in the curve of distortion against $k$, works when the clusters are clear and is unreliable otherwise. Each criterion today compares the improvement from adding a cluster with the improvement you would expect if there were no new structure to find.

  import numpy as np
  import matplotlib.pyplot as plt

  def kmeans(X, k, g, restarts=3, iters=60):
      best = None
      for _ in range(restarts):
          C = X[g.choice(len(X), k, replace=False)]
          lab = None
          for _ in range(iters):
              new = np.argmin(((X[:, None] - C[None]) ** 2).sum(-1), 1)
              if lab is not None and np.array_equal(new, lab): break
              lab = new
              C = np.array([X[lab == j].mean(0) if np.any(lab == j) else C[j] for j in range(k)])
          W = ((X - C[lab]) ** 2).sum()
          if best is None or W < best[1]:
              best = (lab, W, C)
      return best

<Step n={2} title="Information criteria for mixtures" minutes={30} />

For a probability model such as a Gaussian mixture, the **Bayesian information criterion** penalises the maximised log-likelihood $\hat\ell$ by the number of free parameters $p$:

$$
\text{BIC} = -2\hat\ell + p\log n.
$$

It approximates $-2$ times the log of the marginal likelihood (Week 68), and the model with the lowest BIC is preferred. A mixture of $K$ Gaussians in $d$ dimensions with full covariances has $p = (K - 1) + Kd + Kd(d + 1)/2$ parameters. An alternative that makes fewer assumptions is the **held-out log-likelihood**: fit on part of the data and score the rest, exactly as in Week 59.

For the four groups, BIC falls from 2,677 with one component to a minimum of 2,374 at four, then rises again: a fifth component improves the log-likelihood by less than the $6\log 300 \approx 34$ it costs. For the single cloud, the minimum is at one component, though two come within 2 units, a reminder that BIC differences of a few units are weak evidence. BIC assumes the model is right: if the true groups are not Gaussian, say skewed or heavy-tailed, BIC will add components to describe their shape, and each group will be split. The fewer assumptions the clusters satisfy, the more the answer reflects the model rather than the data.

<Step n={3} title="The gap statistic" minutes={30} />

Tibshirani, Walther and Hastie (2001), today's paper, proposed a criterion for any clustering method that makes no distributional assumption about the clusters. Compare $\log W_k$, the log distortion with $k$ clusters, with its expected value under a **reference distribution with no clusters**, uniform over the bounding box of the data:

$$
\text{Gap}(k) = E^*[\log W_k^*] - \log W_k,
$$

estimated by clustering $B$ reference datasets. Choose the smallest $k$ such that $\text{Gap}(k) \ge \text{Gap}(k + 1) - s_{k+1}$, where $s_{k+1}$ is the standard deviation of $\log W^*_{k+1}$ across reference sets, inflated by $\sqrt{1 + 1/B}$.

The gap for the four groups climbs slowly to $k = 3$ and then jumps at $k = 4$, from 0.43 to 0.92: four clusters reduce distortion far more than they would in structureless data. The rule stops at 4 because the gap at 5 is no larger. For the single cloud the gap is largest at $k = 1$ and falls from there, so the rule chooses one cluster, the right answer, which the elbow method cannot give since it never considers $k = 1$ against anything. The uniform reference has a known weakness: in elongated data a uniform box is a poor null, and Tibshirani and colleagues suggest drawing the reference in the frame of the principal components instead.

<Step n={4} title="Stability, and data with no clusters" minutes={30} />

A third idea asks whether the clustering would come out the same on different data from the same source. Draw two random halves of the data, cluster each, use each half's centres to label all the points, and measure how often pairs of points that are together in one labelling are together in the other. Real clusters are found again; arbitrary cuts through a continuum move from sample to sample. Stability has a known weakness, which you will meet: $k = 2$ is often stable even when there is no structure, because a cloud can be cut in half the same way each time.

For the four groups, $k = 4$ is almost perfectly stable, 0.995, while 3, 5 and 6 are less so: with three clusters, which two groups get merged changes from sample to sample. For the single cloud, no $k$ above 2 is stable, but $k = 2$ scores 0.86, higher than $k = 2$ on the real groups. A cloud cut in half along its long axis is cut the same way every time, so stability alone would declare two stable clusters in data that have none. Stability answers "is this partition reproducible?", which is not the same question as "are there clusters?", so use it together with a criterion like the gap that compares against no structure.

<Callout kind="warning" title="Discrete types or a continuum?">

The criteria of today all assume that the question "how many clusters?" has an answer. For neurons it often does not: transcriptomic and physiological studies find some sharply distinct classes, such as excitatory and inhibitory cells, and within them graded variation along continua, so that the number of types depends on the resolution at which one looks. When the criteria disagree, or when the choice changes with the sample, the honest report is the structure itself, a continuum or a hierarchy, rather than a number. Day 4 introduces hierarchical clustering, which reports structure at every resolution at once.

</Callout>
