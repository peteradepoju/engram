<Step n={1} title="How UMAP works" minutes={25} />

UMAP (McInnes, Healy and Melville, 2018) builds a weighted **k-nearest-neighbour graph** of the data: each point connects to its $k$ nearest neighbours with weights that fall off with distance beyond the nearest one, scaled per point much as perplexity scales t-SNE's bandwidths, and the directed weights are combined by a fuzzy union, $w_{ij} = a + b - ab$. It then lays out the graph in two dimensions by minimising a **cross-entropy** between the graph weights and similarities in the embedding, $v_{ij} = (1 + a'd_{ij}^{2b'})^{-1}$:

$$
\sum_{ij}\left[w_{ij}\log\frac{w_{ij}}{v_{ij}} + (1 - w_{ij})\log\frac{1 - w_{ij}}{1 - v_{ij}}\right].
$$

The first term attracts neighbours, as in t-SNE; the second explicitly repels non-neighbours. Optimisation uses stochastic gradient descent with negative sampling, which is why UMAP scales to millions of points, and the layout starts from a **spectral embedding**, the Laplacian eigenvectors of Week 60. Böhm, Berens and Kobak (2022) showed that UMAP and t-SNE behave alike when given the same initialisation, and that UMAP's tighter clusters come mainly from weaker repulsion: the methods lie on one spectrum of attraction against repulsion.

<PyCell code={String.raw`
  import numpy as np
  import matplotlib.pyplot as plt

  def sqdist(A):
      s = (A ** 2).sum(1)
      return np.maximum(s[:, None] + s[None] - 2 * A @ A.T, 0)

  def joint_p(X, perp):
      D2 = sqdist(X); n = len(X); P = np.zeros((n, n)); target = np.log(perp)
      for i in range(n):
          d = np.delete(D2[i], i); lo, hi, beta = 0.0, np.inf, 1.0 / np.median(d)
          for _ in range(60):
              p = np.exp(-(d - d.min()) * beta); p /= p.sum()
              H = -(p * np.log(np.maximum(p, 1e-300))).sum()
              if abs(H - target) < 1e-4: break
              if H > target: lo = beta; beta = beta * 2 if hi == np.inf else (beta + hi) / 2
              else: hi = beta; beta = (beta + lo) / 2
          P[i, np.arange(n) != i] = p
      return (P + P.T) / (2 * n)

  def tsne(X, perp=30, iters=500, seed=0, init=None, exaggeration=12.0):
      P = joint_p(X, perp)
      g = np.random.default_rng(seed)
      Y = 1e-4 * g.normal(size=(len(X), 2)) if init is None else init.copy()
      V = np.zeros_like(Y)
      for it in range(iters):
          exag, mom = (exaggeration, 0.5) if it < 100 else (1.0, 0.8)
          W = 1 / (1 + sqdist(Y)); np.fill_diagonal(W, 0); Q = W / W.sum()
          M = (exag * P - Q) * W
          V = mom * V - 100 * 4 * (M.sum(1)[:, None] * Y - M @ Y)
          Y = Y + V
      return Y

  def silhouette(Z, lab):
      D = np.sqrt(sqdist(Z)); s = []
      for i in range(len(Z)):
          same = lab == lab[i]; same[i] = False
          a = D[i, same].mean()
          b = min(D[i, lab == c].mean() for c in np.unique(lab) if c != lab[i])
          s.append((b - a) / max(a, b))
      return np.mean(s)
  print("ready: tsne(X, perp, iters, seed, init) and silhouette(Z, labels)")

The population vectors trace a smooth ring: in the data the largest step between neighbouring angles is only 1.3 times the median, and in the PCA plane 2.4 times, where the ring is slightly squashed. The t-SNE embedding at perplexity 5 has a step 9.4 times the median: the ring has been torn open, and with other seeds or smaller perplexity it can split into several arcs. Each point's five effective neighbours are its nearest angles, so t-SNE only has to keep short arcs intact; where the arcs join matters little to the objective. A reader shown only the embedding might conclude that head direction is coded by a few discrete groups.

In the 30-dimensional noise, six k-means clusters have a silhouette of 0.02, which means no structure at all: points are as close to other clusters as to their own. In the embedding the same procedure gives 0.34, the value of moderately well-separated clusters. Small perplexity makes t-SNE gather each point's few nearest neighbours tightly, and random fluctuations in density become visible clumps. Cluster the original data, or test the embedding's clusters against embeddings of shuffled data, before treating such clumps as groups.

<Step n={4} title="Initialisation and global structure" minutes={25} />

Kobak and Berens (2019), today's paper, showed that much of what makes UMAP seem better at global structure than t-SNE is its spectral initialisation, and that t-SNE started from the first two principal components (scaled small) keeps global structure about as well. Random initialisation leaves the arrangement of clusters to chance, and only tricks such as early exaggeration rescue it some of the time. To see the effect of the start alone, today's cell switches exaggeration off.

Without early exaggeration, the four random starts give correlations between centre distances of 0.34, 0.98, 0.88 and 0.99: one run scrambled the order of the clusters badly and another partly. The PCA start gives 0.98, and gives it every time, because the clusters begin in the right global arrangement and the optimisation only has to refine the local structure. Early exaggeration rescues most random starts in small datasets like this one, but becomes less effective as datasets grow, which is why Kobak and Berens recommend PCA initialisation, together with larger perplexities for large datasets, as defaults.

<Callout kind="note" title="Rules for embeddings">

<ul>
<li>Use an embedding to look, not to measure. Compute cluster counts, sizes, distances and separability in the original space or with a model.</li>
<li>Initialise informatively (PCA or spectral), set perplexity or the number of neighbours deliberately, and show more than one setting.</li>
<li>Check that islands are not artefacts: rerun with different seeds and subsamples, and look for continua by colouring points by a continuous variable.</li>
<li>Run the same pipeline on shuffled or simulated null data. If it makes islands from noise, its islands in real data need other evidence.</li>
<li>Report the method, its parameters and the preprocessing, since all of them change the picture (Chari and Pachter, 2023).</li>
</ul>

</Callout>

<Key title="Before you go">
<ul>
<li>UMAP lays out a nearest-neighbour graph with attraction and repulsion; it and t-SNE are close relatives.</li>
<li>Neighbour embeddings can break continua, invent clumps and place clusters arbitrarily.</li>
<li>Informative initialisation keeps much more global structure.</li>
<li>Measure in the data, check against nulls, and show several settings.</li>
</ul>
