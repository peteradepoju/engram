<Step n={1} title="Spike words" minutes={20} />

Bin the spike trains of $N$ neurons into short windows, 20 ms in Schneidman and colleagues' study, and write each window as a binary **word** $\boldsymbol\sigma \in \{0, 1\}^N$. With ten neurons there are 1,024 possible words, few enough to estimate each one's frequency from an hour of recording and to compute any model's partition function exactly. The question is how well models with few parameters predict those 1,024 frequencies. The independent model uses $N$ firing rates; the pairwise model adds $N(N - 1)/2$ correlations,

$$
p(\boldsymbol\sigma) = \frac1Z\exp\left(\sum_ih_i\sigma_i + \sum_{i \lt j}J_{ij}\sigma_i\sigma_j\right),
$$

the maximum entropy distribution with those rates and correlations (Day 3).

The setup cell simulates a "recording": 30,000 bins from ten neurons whose true statistics come from a pairwise model with weak couplings.

<PyCell code={String.raw`
  import numpy as np
  import itertools
  import matplotlib.pyplot as plt
  N = 10
  W = np.array(list(itertools.product((0, 1), repeat=N)), dtype=float)       # all 1,024 words

  def model_probs(h, J):
      E = W @ h + 0.5 * np.einsum("ki,ij,kj->k", W, J, W)
      E -= E.max()
      p = np.exp(E)
      return p / p.sum()

  g0 = np.random.default_rng(625)
  h_true = g0.uniform(-3.0, -2.2, N)
  J_true = np.triu(g0.normal(0.25, 0.25, (N, N)), 1); J_true = J_true + J_true.T
  p_true = model_probs(h_true, J_true)
  idx = g0.choice(len(W), size=30000, p=p_true)
  words = W[idx]
  counts = np.bincount(idx, minlength=len(W))
  p_emp = counts / counts.sum()
  rates = words.mean(0)
  C = np.corrcoef(words.T)
  print(f"firing probability per bin: {rates.min():.3f} to {rates.max():.3f}")
  print(f"pairwise correlations: mean {C[np.triu_indices(N, 1)].mean():.3f}, range {C[np.triu_indices(N, 1)].min():.3f} to {C[np.triu_indices(N, 1)].max():.3f}")

<Step n={2} title="Fitting by moment matching" minutes={30} />

The log-likelihood of an exponential-family model has a simple gradient: the data average of each statistic minus its model average. For the pairwise model,

$$
\frac{\partial\ell}{\partial h_i} = \langle\sigma_i\rangle_{\text{data}} - \langle\sigma_i\rangle_{\text{model}},\qquad \frac{\partial\ell}{\partial J_{ij}} = \langle\sigma_i\sigma_j\rangle_{\text{data}} - \langle\sigma_i\sigma_j\rangle_{\text{model}}.
$$

At the maximum the model's moments equal the data's: maximum likelihood and maximum entropy give the same answer. The likelihood is concave, so gradient ascent finds the unique optimum. With ten neurons the model averages are exact sums over the 1,024 words.

After gradient ascent the fitted model reproduces every firing rate and every pairwise product of the data to five decimal places, as maximum entropy requires, and its couplings correlate at 0.97 with the true ones. The likelihood is concave, so there are no local optima to worry about; the only difficulty is computing the model's moments, which here took a sum over 1,024 words per step. Note that the couplings are not the correlations: a pair with a near-zero correlation can have a clearly non-zero coupling, offset by indirect paths through other neurons.

Schneidman and colleagues summarised the comparison with the **multi-information**, $I_N = S_1 - S_N$, the entropy of the independent model minus the true entropy: the total amount of structure beyond independence. The pairwise model has entropy $S_2$ between them, and the fraction $(S_1 - S_2)/(S_1 - S_N)$ is how much of that structure pairwise correlations account for. In the retina they found about 90%.

In the data, six or more of the ten neurons fire together in 0.17% of bins. The independent model predicts 0.009%, almost twenty times too rare; the pairwise model predicts 0.21%, close to the truth. The scatter plot tells the same story word by word: the independent model's predictions for common multi-spike words fall far below the diagonal, while the pairwise model's lie along it. Pairwise correlations account for 91% of the multi-information. Because the data here came from a pairwise model, the remaining 9% is the cost of estimating from finite data; in the real retina, the missing fraction also includes genuine higher-order structure.

<Step n={4} title="Boltzmann learning for larger populations" minutes={30} />

With 40 neurons there are about $10^{12}$ words and the model averages cannot be summed. Ackley, Hinton and Sejnowski (1985) faced the same problem in **Boltzmann machines** and estimated the model averages from samples: run Gibbs sampling in the current model, measure its moments, and step the parameters along the difference from the data. Keeping a set of sampling chains running between parameter updates, rather than restarting them, makes each step cheap (**persistent contrastive divergence**, Tieleman, 2008).

With moments estimated from 3,000 persistent chains, 150 learning steps bring the model's pairwise correlations into line with the data's (r = 0.89 across the 300 pairs), with no partition function ever computed. The match is limited by sampling noise in both the data and the chains, since correlations of a few hundredths are hard to estimate, and the mean model correlation, 0.059 against 0.067, is still slightly low after 150 steps. Real applications run thousands of steps with careful learning rates, or use faster approximations such as pseudo-likelihood.
